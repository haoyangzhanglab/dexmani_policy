# 观测预训练

AFRO 和 CordViP 先从观测学习表征，再用示教动作训练策略。两者均通过 `initialization.encoder=<run>/encoder.pt` 载入编码器与输入归一化参数。

| 方法 | 预训练目标 | 下游训练 |
| --- | --- | --- |
| AFRO | 从相邻场景点云推断隐式动作，预测正向和反向变化 | 载入并冻结在线场景编码器，训练状态编码器和动作生成器 |
| CordViP | 从手部与物体点云预测逐点接触，根据视觉和状态表征重建手臂与手部状态 | 微调整个交互编码器 |

## AFRO

AFRO 默认训练 301 轮。正式实验通过 `initialization.encoder` 指定导出的编码器。默认空权重与冻结视觉编码器的组合用于随机特征消融。

在仓库根目录运行 `bash scripts/pretrain/afro.sh`。默认从原始示教取 33 帧窗口，采样步幅为 2，由 EMA 教师提供目标场景表征。 [AFRO 预训练配方](../dexmani_policy/configs/pretrain/obs/afro.yaml)

## CordViP

CordViP 默认训练 1,000 轮，前 500 次更新用于学习率预热，随后按完整预算做余弦衰减。以 `pick_apple_messy`、batch 256、划分种子 42 且验证回合数为 0 为例，选取 50、100、150 个示教回合分别对应 36,000、71,000、106,000 次更新。每 100 轮及结束时保存 `checkpoints/latest.pt`。

默认接触监督需要与物体点云逐点对应的 `contact_map`。在 `policy` 环境从原始示教生成接触标签，再训练编码器。

```bash
python -m pip install -e '.[preprocess]'
ZARR=robot_data/dexmani_sim/pick_apple_messy.zarr
python -m dexmani_policy.datasets.preprocess.contact_map --zarr-path "$ZARR"
bash scripts/pretrain/cordvip.sh task_name=pick_apple_messy
```

预训练默认读取原始 Zarr 同级 `cordvip/` 目录中的同名数据。只训练协调表征时，可用 `--zarr-path` 指向原始 Zarr，设置 `model.contact_loss_weight=0` 并保留协调损失。下游策略使用原始 Zarr。

接触标签可用 `contact_map --output` 写到新位置，再用预训练的 `--zarr-path` 指定该位置。

AFRO 和 CordViP 主实验均迁移预定末轮的在线编码器。使用 `--max-updates` 提前结束也会导出当时的 `encoder.pt`。可查看 `checkpoints/latest.pt` 的 `global_step` 核实进度，使用对应预训练脚本的 `--resume-from RUN_DIR` 沿原配方续训。若末轮 checkpoint 已写入，执行同一续训命令会从中重新导出编码器。

## 同源数据预算

两个阶段使用同一份原始示教，按相同的原始回合分组和顺序划分。以下示例复用同一组 Hydra 参数。

```bash
PRETRAIN=experiments/pretrain/afro/pick_apple_messy/run01
SPLIT=(dataset.seed=42 dataset.val_episodes=20 dataset.max_train_episodes=100)
bash scripts/pretrain/afro.sh "${SPLIT[@]}" --output-dir "$PRETRAIN"
bash scripts/training/train.sh afro "${SPLIT[@]}" initialization.encoder="$PRETRAIN/encoder.pt"
```

运行配置记录数据路径和实际回合组。归一化拟合与梯度更新使用训练组。报告实际训练和验证组数，例如 100 个训练回合另加 20 个验证回合。下游策略使用选模种子比较 checkpoint，再用独立测试种子报告成功率。跨任务预训练单列来源和回合数。 [仿真评测机制](仿真评测机制.md)
