# 观测预训练

AFRO 和 CordViP 先从观测学习表征，再用示教动作训练策略。两者均通过 `initialization.encoder=<run>/encoder.pt` 载入编码器及输入归一化参数。

| 方法 | 预训练目标 | 策略训练 |
| --- | --- | --- |
| AFRO | 从相邻场景点云推断隐式动作，预测正向和反向变化 | 默认冻结场景编码器，继续学习状态编码和动作生成 |
| CordViP | 用手部和物体点云预测逐点接触，从视觉与臂手状态表征重建最新的手臂和手部状态 | 微调整个交互编码器 |

## AFRO

在仓库根目录运行 `bash scripts/pretrain/afro.sh`。AFRO 用独立初始化的 EMA 教师提供目标表征。VICReg 依赖批统计，因此固定 `training.loop.gradient_accumulation_steps=1`。各次验证复用同一扩散随机序列。

默认取完整的 33 帧窗口，采样步幅为 `frame_stride=2`。设置 `dataset.pad_after=7` 可复现尾部 padding，补齐时重复最后一帧。

## CordViP

在仓库根目录使用已有的 CordViP 派生 Zarr 启动预训练，默认任务为 `pick_apple_messy`。

```bash
bash scripts/pretrain/cordvip.sh
```

用 `task_name` 选择其他任务，例如运行 `bash scripts/pretrain/cordvip.sh task_name=multi_grasp`。

若所选任务还没有派生 Zarr，在仓库根目录激活 `policy` 环境，从该任务的原始示教生成与物体点云逐行对应的 `contact_map[T,N]`。

```bash
python -m pip install -e '.[preprocess]'
ZARR=robot_data/dexmani_sim/pick_apple_messy.zarr
python -m dexmani_policy.datasets.preprocess.contact_map --zarr-path "$ZARR"
```

预处理默认在原始 Zarr 同级的 `cordvip/` 子目录生成同名数据。CordViP 配方默认读取 `robot_data/dexmani_sim/cordvip/${task_name}.zarr`。若用 `--output` 改路径，预训练时用 `--zarr-path` 指定该数据。点对计算默认使用 CPU，可指定 `--device cuda:0`。

只训练协调时，用 `--zarr-path` 指向原始 Zarr，设置 `model.contact_loss_weight=0`，并保留至少一个协调损失。下游策略始终使用原始 Zarr。

## 同源数据预算

`--policy-config` 从已解析的策略配置复用任务、原始 Zarr 和数据划分。CordViP 启用接触损失时默认读取对应的派生 Zarr，派生数据须保留原始回合布局。以下以 AFRO 为例。

```bash
POLICY_CONFIG=afro-budget.yaml
PRETRAIN=experiments/pretrain/afro/pick_apple_messy/run01
SPLIT=(dataset.seed=42 dataset.val_episodes=20 dataset.max_train_episodes=100)
bash scripts/training/train.sh afro --cfg job --resolve "${SPLIT[@]}" > "$POLICY_CONFIG"
bash scripts/pretrain/afro.sh --policy-config "$POLICY_CONFIG" --output-dir "$PRETRAIN"
bash scripts/training/train.sh afro "${SPLIT[@]}" initialization.encoder="$PRETRAIN/encoder.pt"
```

预训练更新和归一化拟合只使用训练组。加载同源先验时，策略分别核对训练组与验证组是否超出本次划分。外部或独立数据训练的先验标记为预算未核验。

用预训练脚本的 `--resume-from <run>` 从 `checkpoints/latest.pt` 恢复，沿用原 Zarr 和数据划分。编码器迁移后，用下游闭环评测衡量收益。 [仿真评测机制](仿真评测机制.md)
