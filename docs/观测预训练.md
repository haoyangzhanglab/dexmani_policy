# 观测预训练

AFRO 与 CordViP 用观测训练编码器，再将学到的表征迁移到使用示教动作的策略。

## 两种学习目标

| 方法 | 输入 | 核心目标 |
| --- | --- | --- |
| AFRO | 场景点云序列 | 用隐式动作解释并预测相邻场景的变化 |
| CordViP | 手部与物体点云、关节状态及接触标签 | 学习手物接触和手臂、手部的协调关系 |

## AFRO：学习场景动力学

AFRO 从相邻观测的点云特征推断隐式动作，并预测正向与反向的场景变化。目标表征来自独立初始化的 EMA 教师。VICReg 依赖批统计，预训练固定 `gradient_accumulation_steps=1`。各次验证复用相同的扩散随机序列。

默认窗口为 33 帧，`frame_stride=2`，只取完整窗口。复现官方尾部 padding 时可设置 `dataset.pad_after=7`，尾部重复帧会缩短实际帧间隔。

## CordViP：学习接触与协调

CordViP 联合编码手部和物体点云以及关节状态，重建手物接触、手臂状态和手部状态。协调重建以同一时刻的完整关节状态为条件。

预处理按每帧物体点云的行顺序生成逐点接触标签 `contact_map[T,N]`，保留点云及其原始 Zarr 路径。不同回合可使用各自的物体模板。以下命令在已激活 `policy` 环境的仓库根目录运行。

```bash
python -m pip install -e '.[preprocess]'
ZARR=robot_data/pick_apple_messy.zarr
python -m dexmani_policy.datasets.preprocess.contact_map --zarr-path "$ZARR"
bash scripts/pretrain/cordvip.sh
```

预处理默认生成 `robot_data/cordvip/pick_apple_messy.zarr`，保留输入文件名。可用 `--output` 指定其他位置，再用预训练的 `--zarr-path` 读取。预训练在实验目录生成可用于策略初始化的 `encoder.pt`、用于续训的 `checkpoints/latest.pt`，以及配置和训练指标。

预处理默认使用 CPU，可指定 `--device cuda:0` 在 GPU 上计算点对。只训练协调目标时，可直接使用 `--zarr-path "$ZARR" model.contact_loss_weight=0` 并保留至少一个协调损失。下游策略使用原始 Zarr。

## 同源数据预算

预训练通过 `--policy-config` 复用下游任务和数据划分。CordViP 启用接触时，从原始 Zarr 旁的 `cordvip/` 子目录读取同名数据。自定义输出用 `--zarr-path` 指定。以下以 AFRO 为例。

```bash
POLICY_CONFIG=afro-budget.yaml
PRETRAIN=experiments/pretrain/afro/pick_apple_messy/run01
SPLIT=(dataset.seed=42 dataset.val_episodes=20 dataset.max_train_episodes=100)
bash scripts/training/train.sh afro --cfg job --resolve "${SPLIT[@]}" > "$POLICY_CONFIG"
bash scripts/pretrain/afro.sh --policy-config "$POLICY_CONFIG" --output-dir "$PRETRAIN"
bash scripts/training/train.sh afro "${SPLIT[@]}" initialization.encoder="$PRETRAIN/encoder.pt"
```

预训练更新和归一化拟合只使用训练组，验证组可用于选模。对同一原始 Zarr，策略分别核对先验的训练组和选模组。接触派生数据需与原始 Zarr 共享回合布局。独立数据训练的先验会记录为预算未核验。

AFRO 和 CordViP 续训使用 `--resume-from RUN`。续训使用原运行的 checkpoint、Zarr、回合布局和数据划分。

## 迁移到动作策略

| 方法 | 迁移内容 | 下游学习方式 |
| --- | --- | --- |
| AFRO | 在线场景编码器及其输入变换 | 默认冻结场景编码器，学习状态编码与动作生成 |
| CordViP | 完整交互编码器及其输入变换 | 微调交互编码器并学习动作生成 |

动力学模型、教师分支及接触与协调预测头只服务于预训练。表征收益通过下游闭环任务表现检验。 [仿真评测机制](仿真评测机制.md)
