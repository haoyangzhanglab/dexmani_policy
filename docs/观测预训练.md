# AFRO 与 CordViP 观测预训练

观测预训练先从场景变化或手物交互中学习表征，再把编码器迁移到动作策略。AFRO 学习场景随时间如何变化；CordViP 学习手与物体的接触关系以及手臂与手部的协调关系。两者的预训练都不依赖示范动作标签，下游策略仍使用真实动作进行模仿学习。

公共策略结构见[项目架构](项目架构.md)，输入字段、坐标和动作语义见[仿真数据集格式](仿真数据集格式.md)。本篇说明预训练的学习目标，以及迁移时保留什么。

## 两种方法的分工

|  | AFRO | CordViP |
| --- | --- | --- |
| 预训练输入 | 场景 XYZ 点云序列 | 手部与物体 XYZ 点云、关节状态、接触标签 |
| 核心目标 | 用隐式动作解释并预测相邻场景表征的变化 | 重建接触关系及手臂、手部的协调状态 |
| 编码器 | 场景 PointNet | 手物点云与手臂、手部状态的交互编码器 |
| 迁移内容 | 在线场景编码器及点云归一化统计 | 交互编码器及其输入归一化统计 |
| 下游学习 | 默认冻结场景编码器，学习状态编码和动作生成 | 微调整个交互编码器并学习动作生成 |

预训练只提供观测表征。两种下游策略都将观测特征交给条件 Diffusion 模型，生成 19 维关节动作序列。

## AFRO：从场景变化学习隐式动作

AFRO 使用一个在线点云编码器和一个无梯度的 teacher 编码器，将相邻场景转换为特征。teacher 通过在线编码器参数的指数移动平均更新，提供随训练变化的预测目标。

其学习过程为：

1. 在线编码器提取相邻两帧的场景特征。
2. 逆动力学模型根据两帧特征之差推断 16 维 latent action，表示这段场景变化中的隐式动作。
3. 前向动力学模型结合当前特征、latent action 和含噪的目标特征，预测另一时刻的 teacher 特征。
4. 在时间正向和反向分别学习上述预测，使表征能够描述双向变化。

latent action 来自场景变化，不是机器人记录的关节命令。AFRO 因此可以仅使用点云序列进行预训练，无需读取动作或关节状态。

预测使用 VICReg 目标：特征一致性项使预测接近 teacher，方差项避免特征退化为常量，协方差项减少特征维度之间的冗余。正反两个方向分别计算这些约束后合并。

迁移时只保留在线场景编码器。teacher、逆动力学模型和前向动力学模型是预训练辅助组件，不参与下游动作生成。默认下游冻结该场景编码器，将其特征与可训练的关节状态特征组合后用于策略学习。

## CordViP：接触与协调表征

CordViP 将观测分为四部分：手部点云、物体点云、手部关节状态和手臂关节状态。点云分别由 PointNet 编码，关节状态分别投影到特征空间。

交叉注意力在两组关系中交换信息：手部点云与物体点云相互关注，手部状态与手臂状态相互关注。编码器由此输出四组带交互信息的特征。

预训练通过三个重建目标塑造这些表征：

| 目标 | 条件特征 | 监督信号 |
| --- | --- | --- |
| 接触 | 手部与物体点云的交互特征 | 每帧物体点云上的连续接触标签 |
| 手臂协调 | 点云交互特征与手部状态特征 | 最后观测时刻的手臂关节状态 |
| 手部协调 | 点云交互特征与手臂状态特征 | 最后观测时刻的手部关节状态 |

三个目标使用加权均方误差。协调目标重建的是观测窗口末端的状态，不是未来动作；接触标签仅用于预训练监督，不作为策略运行时的输入。

状态特征已通过交叉注意力读取另一状态模态，重建条件中可能包含目标模态的信息。因此应将其理解为接触与协调表征学习，不能解释为严格遮挡某个模态后的预测任务。

迁移时保留完整交互编码器，舍弃接触和协调预测头。下游将四组特征组合为动作生成条件，并微调编码器。共享编码器与依赖窗口长度的预测头分离，因此预训练和下游可以使用不同长度的观测窗口。

## 接触标签与数据假设

CordViP 的接触标签由同帧手部与物体点云的几何关系离线生成，依据空间距离和物体局部法向构造连续值。标签与观测保持相同的帧序和物体点序，不依赖动作命令。

当前接触预测头为物体点云输出 1024 个值，依赖物体点序在数据中的稳定对应关系。全局 PointNet 特征本身对点排列不变，不能把它理解为已建立逐点语义对应的局部特征。

预训练与下游应使用一致的字段含义、世界坐标系、米制 XYZ 和关节顺序。AFRO 学习场景点云变化，CordViP 依赖明确区分的手部与物体点云；两者的语料要求不同。

## 编码器与归一化一起迁移

预训练得到的编码器依赖其输入尺度，因此迁移时同时继承对应输入的归一化统计。新出现的字段由下游训练数据建立自己的尺度。

| 下游初始化方式 | 继承的统计 | 下游拟合的统计 |
| --- | --- | --- |
| AFRO 预训练初始化 | 场景点云 | 关节状态、动作 |
| CordViP 预训练初始化 | 手部点云、物体点云、关节状态 | 动作 |
| 从头训练 | 无 | 全部使用的字段 |

最终策略包含编码器与已经确定的全部统计，评测和部署沿用这组状态。公共归一化与训练划分原则见[项目架构](项目架构.md)。

预训练和下游可以使用独立语料，但若要用 held-out 数据评价完整训练流程，预训练也应避开这些数据。仅在下游留出验证集，不能消除预训练阶段的数据泄漏。

## 结果含义与方法来源

AFRO 与 CordViP 的预训练验证用于诊断各自的表征目标；当前迁移的是最终在线编码器，AFRO 不默认使用 teacher，也不根据预训练验证误差选择下游模型。

预训练损失下降说明对应辅助目标拟合改善，是否有利于动作策略还需比较下游闭环表现。评测应保持示范预算、任务条件与推理预算可比，具体见[仿真评测机制](仿真评测机制.md)。

本地实现保留上述方法目标，并采用本项目的机器人、数据字段和下游动作生成模型。来源为 [AFRO](https://github.com/KolaKivy/AFRO/tree/283024a49e2c14bc030debf15383a4e7ee73836d) 与 [CordViP](https://github.com/xuanxuanzzzii/cordvip/tree/ad6d441abe7b0480cf79b0311db266965c1313b6)。
