# AFRO 与 CordViP 观测预训练

编码器将点云或关节状态变成特征向量，也称为表征，用来为动作生成提供条件。观测预训练先让这些特征能够描述场景变化或手物交互，再把编码器用于策略学习。

AFRO 与 CordViP 都不依赖示教动作标签进行预训练。它们学习观测中的结构，下游策略再使用真实动作做模仿学习，通过条件 Diffusion 模型生成关节目标。

## 两种方法分别学习什么

|  | AFRO | CordViP |
| --- | --- | --- |
| 预训练输入 | 场景 XYZ 点云序列 | 手部与物体 XYZ 点云、关节状态、接触标签 |
| 学习目标 | 用隐式动作解释并预测相邻场景的变化 | 重建手物接触关系与手臂、手部的协调状态 |
| 编码方式 | 场景 PointNet | 点云、关节状态与交叉注意力组成的交互编码器 |

## AFRO：用场景变化学习隐式动作

AFRO 将相邻两帧场景编码为特征，用两帧特征之差提取一个变化摘要，称为隐式动作（latent action）。例如，物体的位置和姿态发生变化时，这个向量用来描述两帧之间的变化，无需知道机器人实际发出了什么关节命令。其各维也不要求与真实控制量逐项对应。

预训练包含一对动力学模型：逆动力学模型从两帧差异中提取隐式动作，前向动力学模型再利用当前特征和隐式动作预测另一时刻的特征。同一对帧既做正向预测，也交换顺序做反向预测。

为了构造缓慢变化的学习目标，AFRO 还保留一个教师编码器（teacher）。正在训练的编码器称为在线编码器；teacher 不直接接受损失的反向传播，而是通过指数移动平均（EMA）逐步向在线编码器靠近。

具体学习过程为：

1. 在线编码器提取相邻两帧特征，逆动力学模型据此提取隐式动作。
2. teacher 为目标帧提供特征，并对该目标特征加噪。
3. 前向动力学模型结合当前在线特征、隐式动作和含噪目标，预测无噪的 teacher 目标特征。
4. 分别计算正向、反向预测的损失，再更新在线编码器及动力学模型。

预测使用 VICReg 目标：一致性项要求预测接近 teacher；方差项避免所有输入被编码成相同特征；协方差项减少不同特征维度的冗余。这样既学习时序变化，也抑制表征退化。

## CordViP：学习接触与手臂、手部的协调

CordViP 分别编码每帧的手部点云、物体点云、手部关节状态和手臂关节状态。PointNet 将点云汇总为整体特征，关节状态则投影为相应的状态特征。

随后，两组特征通过交叉注意力交换信息：手部点云特征与物体点云特征相互关注，手部状态特征与手臂状态特征相互关注。注意力作用于整个观测窗口，使每帧表征可以利用窗口内其他时刻的信息，最终得到四组带交互信息的表征。

预训练使用三个重建目标：

| 目标 | 预测所用的特征 | 要重建的内容 |
| --- | --- | --- |
| 接触 | 手部与物体的点云交互特征 | 每帧物体点云上的连续接触标签 |
| 手臂协调 | 点云交互特征、手部状态特征 | 最后观测时刻的手臂关节状态 |
| 手部协调 | 点云交互特征、手臂状态特征 | 最后观测时刻的手部关节状态 |

三个目标使用加权均方误差。协调目标描述观测窗口末端的状态，不是未来动作；接触标签是训练监督，不作为下游策略的观测输入。

两组状态特征已通过交叉注意力交流过信息。例如，预测手臂状态时，所用的手部特征可能已包含手臂信息。因此，这些目标用于塑造接触与协调表征，不能解释为严格遮挡目标模态后的预测。

## 接触监督依赖什么

CordViP 的接触标签由同帧手部与物体点云的几何关系生成，依据空间距离和物体局部法向得到连续值。它是几何监督量，不等同于实测触觉力。

标签与观测使用相同帧序和物体点序。当前接触预测头输出 1024 个值，要求每个输出槽与对应物体点的含义稳定；点云被编码为整体特征，并不意味着模型已建立逐点语义对应关系。

预训练与下游必须保持输入字段的含义、坐标和单位一致。AFRO 只需要场景点云序列，CordViP 则需要明确区分手部、物体以及对应的接触监督；字段约定见[仿真数据集格式](仿真数据集格式.md)。

## 迁移到动作策略

预训练结束后保留最终编码器及其输入归一化统计。编码器依赖预训练时的输入尺度，不能只迁移权重、再任意更换这些尺度。其余预训练辅助模块不参与下游动作生成。

| 方法 | 保留与舍弃 | 下游如何学习 |
| --- | --- | --- |
| AFRO | 保留在线场景编码器；舍弃 teacher、逆动力学和前向动力学模型 | 默认冻结场景编码器，训练关节状态编码器和动作生成模型 |
| CordViP | 保留完整交互编码器；舍弃接触与协调预测头 | 微调交互编码器并训练动作生成模型 |

CordViP 的共享编码器与依赖窗口长度的预测头分离，因此预训练和下游可以使用不同长度的观测窗口。

两种方法继承的输入尺度不同：

| 初始化方式 | 从预训练继承 | 由下游训练数据拟合 |
| --- | --- | --- |
| AFRO | 场景点云统计 | 关节状态、动作统计 |
| CordViP | 手部点云、物体点云、关节状态统计 | 动作统计 |

最终策略同时保留权重与已经确定的全部统计。公共架构、归一化与数据划分原则见[项目架构](项目架构.md)；若用留出数据评价完整训练流程，预训练也应避开这些数据。

## 如何判断预训练是否有效

预训练验证只用于诊断相应的表征目标，当前迁移最终训练得到的编码器，AFRO 使用在线分支。预训练损失下降不直接证明策略表现改善，还需在相同任务协议和可比预算下比较下游闭环结果，见[仿真评测机制](仿真评测机制.md)。

本地实现保留上述学习目标，并采用本项目的机器人、数据字段和动作生成模型。方法来源为 [AFRO](https://github.com/KolaKivy/AFRO/tree/283024a49e2c14bc030debf15383a4e7ee73836d) 与 [CordViP](https://github.com/xuanxuanzzzii/cordvip/tree/ad6d441abe7b0480cf79b0311db266965c1313b6)。
