## 比较预算

当前 resolved 配置：单卡 DP、multitask batch64，其他上述单卡方法 batch128；`ddp/dp` 为 4×48=192，`ddp/multitask_dit` 为 4×16=64。在累积为 1 的名义 100k updates 下分别为 6.4M、12.8M、19.2M、6.4M 窗口。真实尾 batch/累积尾组会影响实际样本量，训练 recipe 现在打印完整 loader 几何的 processed window budget，Trainer 记录 `train/processed_windows`，包含重复采样/DDP padding，不能当成唯一源行数。

后续对照固定数据身份/split、动作表示、观测、backbone、LR、optimizer updates 与实际处理窗口、NFE、selection 预算和 test task→seeds，并重复训练 seed。没有自动统一这些研究变量。保留 Wilson episode 区间，但它不估计跨训练 seed 的方差。
