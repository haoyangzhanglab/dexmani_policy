## 必须保持的契约

- 保留 Zarr、实际窗口与 episode 边界、现有共享 Trainer、完整 checkpoint、EMA teacher、梯度累积和 DDP 正确性。
- 普通策略与 LatentFlow 的训练动作起点不同；普通绝对量按有效训练源行统计，LatentFlow 相对动作按窗口/reference 统计。多任务零采样权重任务当前仍参与统计，不借重构改变。
- Policy 输出完整物理 `future_actions[B,P,D_control]`，完成反归一化、方法解码、历史前缀与辅助维度裁剪。第 i 项对应查询槽位 t 的命令 a[t+i]；仿真和真机不得再解释一次窗口起点。
- 先完整解码再取执行段。执行长度 C 只影响消费；DP3 原 `n_action_steps=8` 导致的 `pad_after=7` 等有效训练值必须保留。既有 eval.action_steps 不改变训练窗口的行为保留。
- 等价重构保持 dtype 与数值路径；当前 Real 输出 float64 不顺手改成 float32。历史 checkpoint/配置使用保存事实，不按当前默认值补齐。
- LAMP 历史来自实际提交/应用目标，LatentFlow reference 保持原始查询语义。LAMP/LatentFlow 当前仅 sync；MultiTask 真机尚不支持的路径不能假装支持。
- 现场物理标定、运动学、SDK、限位、运动授权、停止、deadline、Raw 证据与资源关闭留在 Real。
