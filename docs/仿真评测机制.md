# 仿真评测机制

评测从 checkpoint 恢复策略与实验设置，在对应仿真任务的种子池中选取回合。

## 闭环执行

策略读取近期观测、预测未来动作窗口、执行一段动作，再用新观测规划。窗口长度决定规划范围，`--inference-steps` 控制采样步数，`--action-steps` 控制单次执行步数。环境控制周期须与 checkpoint 一致。

扩散策略至少采样两步。ODE 每次执行与训练时相同长度的动作窗口，下一次预测从上一条实际应用的关节目标开始。内置仿真支持关节和末端位姿动作，旋转向量动作需要兼容的运行器。 [ODE 指令衔接](手部动作表示.md#ode从上一条指令积分生成轨迹)

两条评测命令均可加 `--skip-intermediate-observations`，适用于内置仿真且关闭视频时。环境照常执行每条动作并检查回合终止，传感器只采集下一次预测所需的历史帧。被跳过的采集不会消耗对应的传感器随机数，比较时统一设置。结果 JSON 会记录该选项。

## 任务结果与候选选择

固定 checkpoint 用单模型评测。多个 checkpoint 用流水线，在共同的 selection 回合选模，再用不重叠的 test 回合评测胜者。种子池须覆盖两个阶段所需的回合数。将示例路径替换为实际实验和 checkpoint。

```bash
RUN=experiments/train/dp3/pick_apple_messy/run01

bash scripts/eval/evaluate.sh --checkpoint "$RUN/checkpoints/latest.pt" \
  --seed 1024 --episodes 100

bash scripts/eval/eval_pipeline.sh --checkpoints \
  "$RUN/checkpoints/step_00020000.pt" "$RUN/checkpoints/step_00040000.pt" \
  --seed 1024 --selection-episodes 25 --test-episodes 100
```

单模型评测写入 `result_details.json`。省略 `--seeds` 时，同一任务和 seed 池下使用相同的 `--seed` 和测试回合数，即可复用流水线的 test seed。流水线将实际 selection/test seed 和胜者写入 `selection_result.json`。

候选优先按成功率排名，成功率相同时优先选成功回合平均首次达成步数更少的候选，再以训练步数较多者优先。成功率区间反映评测回合的不确定性，多次训练的波动需用多个训练种子衡量。

候选默认使用各自 checkpoint 的权重选择、推理步数和执行长度。流水线可用 `--weights raw` 或 `--weights ema` 指定权重，也可统一 `--inference-steps` 和 `--action-steps`。独立测试沿用胜者选模时的实际设置。需要在多个推理设置间选优时，用单模型命令的 `--seeds` 给每个组合传入同一组 selection seed，再用 test seed 评测胜者。

## 比较条件

候选须使用相同运行器、任务、环境配置和控制周期。比较时固定评测池、`--seed` 和两个阶段的回合数。跨方法还应说明观测模态、先验来源及推理预算。
