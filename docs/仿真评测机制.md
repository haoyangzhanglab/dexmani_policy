# 仿真评测机制

仿真评测衡量策略在环境交互中的任务完成能力。策略从完整 checkpoint 恢复模型、归一化统计与保存的配置，依据仿真环境实际返回的观测持续生成动作。恢复不依赖训练数据或初始预训练权重。

## 闭环执行

每个 episode（回合）从指定 seed 初始化环境。策略读取最近的观测历史，预测一段未来动作，执行其中的前缀，再根据最新历史重新规划，直到环境结束回合。执行前缀期间每一步都会更新观测历史，并检查回合是否终止。

评测输入必须由仿真环境实际提供。当前仿真支持五指汇总（aggregate）接触力，不提供 dense taxel/patch 触觉。接触力沿用仿真世界系物理量及 checkpoint 保存的归一化统计，评测期间不重新拟合统计。

## 预测范围、采样步数与执行长度

| 概念 | 含义 |
| --- | --- |
| 观测历史长度 `n_obs_steps` | 每次预测使用多少帧历史观测 |
| 动作窗口 `horizon` | 模型学习和预测的完整动作窗口长度 |
| 未来动作数 `future_steps` | 从当前观测对应时刻开始，可供执行的动作数 |
| 采样步数 `inference_steps` | 生成一段动作所用的迭代次数 |
| 执行长度 `action_steps` | 每次预测后实际执行的动作前缀长度 |

未来动作数满足 `future_steps = horizon - (n_obs_steps - 1)`，执行长度必须满足 `1 ≤ action_steps ≤ future_steps`。

例如，观测历史为 2 帧、动作窗口为 16 时，一次预测提供 15 个未来动作。若采样步数为 10、执行长度为 4，则每次经过 10 步采样生成整段预测，执行前 4 个动作后，再用最新的 2 帧观测重新规划。修改执行长度改变的是重新调用策略的频率，观测仍在每个控制步更新。

InterAct-Dex 的未来力预测范围由其监督时距决定，与实际执行长度分别定义。AdapTac 的动作扩散与未来力扩散也有各自的采样预算，改变动作采样步数不会自动改变未来力采样步数。

## 成功判定与指标

最终成功由环境返回的 `success` 判定。首次满足原始成功条件的时刻单独记录；经过保持或结束条件后，回合才得到最终成功判定。

| 指标 | 含义 |
| --- | --- |
| `n_episodes` | 实际完成的回合数 |
| `n_success` | 最终成功的回合数 |
| `success_rate` | `n_success / n_episodes` |
| `avg_steps` | 仅对最终成功回合，平均首次满足原始成功条件的步数；无此类回合时为空 |
| `avg_steps_all` | 所有回合结束时的实际动作数均值 |
| `wilson_95` | 按二项比例计算的 95% Wilson 参考区间 |

逐回合的 `steps` 记录首次满足原始成功条件的步数，`total_steps` 记录回合结束时的动作数；因此 `avg_steps` 与 `avg_steps_all` 同时有统计对象和计时终点的区别。

Wilson 区间通常按回合相互独立、成功概率相同的二项模型解释。当前成绩来自固定、筛选过的任务池，不能仅凭这个区间推断任意场景分布上的表现；它也不包含不同训练 seed 造成的波动。

## 评测条件与 seed 池

评测使用 checkpoint 保存的任务与显式环境参数，未保存的选项仍取当前仿真实现的默认值。复现还需保持仿真版本和实际环境设置一致。跨方法比较应保持任务、环境条件、episode seeds 和回合预算一致，并预先声明各方法的权重类型、采样预算与执行长度。同一次候选选择流程统一使用这些推理设置。

常规评测从任务 seed 池中确定性选取回合，也可使用明确的 seed 列表。环境与策略采样使用各自的随机流，并由对应 episode seed 初始化。固定 seed 列表用于约束随机条件，不保证跨环境版本或计算平台的轨迹与结果逐位相同。

项目 seed 池经过生成阶段的专家轨迹筛选，成绩对应这一任务池。seed 列表不包含完整生成配置，历史筛选条件应以生成记录为准，不能由当前默认值倒推。

更换 seed、额外重试或跳过失败回合会改变既定协议和统计分母。成绩的适用范围由任务池来源与实际评测条件共同限定。

## 候选选择与独立测试

研究者明确给出候选 checkpoint，候选可以来自不同训练 run，但必须属于同一任务并满足同一环境协议。模型结构、训练方法和观测模态可以不同；参与比较的候选列表与训练预算须明确。

先从同一任务池固定 test seeds，再从剩余部分取得 selection seeds，二者不相交。划分由 seed 确定，并在比较候选前固定。

| 阶段 | 使用的回合 | 作用 |
| --- | --- | --- |
| 候选选择（Selection） | 所有候选共用 selection seeds 与回合预算 | 按既定排名规则确定一个胜者 |
| 独立测试（Test） | 仅胜者使用 test seeds | 报告最终成绩，不反过来改变胜者 |

Selection 按以下顺序排名：

1. `success_rate` 较高者优先。
2. 成功率相同时，成功回合的 `avg_steps` 较低者优先；缺少该值的候选排在有值者之后。
3. 仍相同时，训练更新数 `global_step` 较大者优先；三项均相同时保留候选列表中较早者。

因此，selection 分数用于作出选择，test 分数用于评价已经选定的策略。不能依据 test 成绩重新挑选候选或回合。

## 结果与胜者复现

一次评测的结果包括实际 checkpoint、权重类型、采样步数、执行长度、seed 列表、环境条件、逐回合成绩与汇总指标。raw 指训练模型参数，EMA 指参数的指数滑动平均版本。带有未来力扩散的模型还记录实际未来力采样步数。控制周期取自实际运行环境，评测不自行改变控制频率。

选模汇总保留候选成绩、胜者、两组 seeds 与独立 test 结果。选模结果不会自动改变部署默认选择；复现胜者需要同时指定记录的 checkpoint、raw/EMA 权重、动作采样步数与执行长度。涉及独立未来力采样时，也须保持相应设置。

模型的训练目标、动作表示及推理过程见[项目架构](项目架构.md)，远程运行操作见[SSH 服务器训练部署](SSH服务器训练部署.md)。
