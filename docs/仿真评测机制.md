# 仿真评测机制

仿真评测衡量策略在环境交互中的任务完成能力。策略从完整 checkpoint 恢复模型、归一化统计与保存的配置，使用仿真环境实际返回的观测生成动作，依据执行后的状态持续更新决策。恢复不依赖训练数据或初始预训练权重。

## 闭环执行

每个 episode 从指定 seed 初始化环境。策略读取最近的观测历史，预测一段未来动作，执行其中的前缀；获得新观测后再次预测，直到环境结束回合。执行前缀期间每一步都会更新历史，并检查回合是否终止。

评测输入必须由仿真环境实际提供。当前仿真支持五指 aggregate 接触力，不提供 dense taxel/patch 触觉。接触力沿用仿真世界系物理量及 checkpoint 保存的归一化统计，评测期间不重新拟合统计。

最终成功由环境返回的 `success` 判定。首次满足原始成功条件的时刻单独记录；它与经过保持或结束条件后判定的最终成功不同。

## 预测范围、采样步数与执行长度

| 概念 | 含义 |
| --- | --- |
| 观测历史长度 `n_obs_steps` | 每次预测使用多少帧历史观测 |
| 动作窗口 `horizon` | 模型学习和预测的完整动作窗口长度 |
| 未来动作数 `future_steps` | 从当前观测对应时刻开始，可供执行的动作数 |
| 采样步数 `inference_steps` | 动作生成过程的迭代次数 |
| 执行长度 `action_steps` | 每次预测后实际执行的动作前缀长度 |

未来动作数满足 `future_steps = horizon - (n_obs_steps - 1)`，执行长度必须满足 `1 ≤ action_steps ≤ future_steps`。修改执行长度会改变重新观察和规划的频率；它不改变模型训练窗口，也不改变一次预测能够覆盖的范围。

InterAct-Dex 的未来力预测范围由其监督时距决定，与每次实际执行几个动作分别定义。AdapTac 的动作扩散与未来力扩散也有各自的采样预算，改变动作采样步数不会自动改变未来力采样步数。

## 评测条件与 seed 池

环境设置沿用 checkpoint 保存的任务与环境参数，已有实验不会被当前训练配置回填。跨方法比较应保持任务、环境条件、episode seeds 和回合预算一致，并预先声明各方法的权重类型、采样预算与执行长度。同一次候选选择流程统一使用这些推理设置。

常规评测从任务 seed 池中确定性选取回合，也可使用明确的 seed 列表。相同 seed 列表与环境参数是复现条件的一部分；环境与策略采样使用各自的随机流，并由对应 episode seed 确定。

既有 seed 池按生成时的专家执行、终止行为及所启用的轨迹质量条件筛选，不能视为任意随机场景的无条件抽样。seed 列表本身不包含完整生成配置；缺少生成记录时，不能从当前默认值倒推历史筛选条件。环境能成功初始化，也不等于已经复现历史接受场景或专家成功轨迹。

评测不能以更换 seed、额外重试或跳过失败回合的方式改变既定协议和统计分母。报告成绩时应同时说明任务池来源与实际评测条件。

## 候选选择与独立测试

研究者明确给出候选 checkpoint，候选可以来自不同训练 run，但必须属于同一任务并满足同一环境协议。模型结构、训练方法和观测模态可以不同；报告应列明实际参与比较的候选与训练预算。

候选选择分为两个阶段：

1. **Selection**：所有候选在同一组 selection seeds 上评测，使用统一的权重类型、采样步数、执行长度与回合预算，并按既定规则选出胜者。
2. **Test**：只将 selection 胜者放到独立 test seeds 上评测，用于报告最终成绩；test 分数不反过来改变胜者。

两组 seeds 来自同一任务池，先固定 test 集，再从剩余部分取得 selection 集，二者不相交。划分由 seed 确定，不能根据候选成绩重新挑选回合。

候选按以下顺序排名：

1. `success_rate` 较高者优先。
2. 成功率相同时，成功回合的 `avg_steps` 较低者优先；没有成功回合、因而缺少该值的候选排在有值者之后。
3. 仍相同时，训练更新数 `global_step` 较大者优先；三项均相同时保留候选列表中较早者。

## 指标解释

| 指标 | 含义 |
| --- | --- |
| `n_episodes` | 实际完成的 episode 数 |
| `n_success` | 最终成功的 episode 数 |
| `success_rate` | `n_success / n_episodes` |
| `avg_steps` | 仅对最终成功回合，平均首次满足原始成功条件的步数；无此类回合时为空 |
| `avg_steps_all` | 所有回合结束时的实际动作数均值 |
| `wilson_95` | 本次成功比例的 95% Wilson 区间 |

逐回合的 `steps` 记录首次满足原始成功条件的步数，`total_steps` 记录回合结束时的动作数。二者分别反映首次达成与最终结束的时刻，不能混用。Wilson 区间描述有限评测回合下的成功比例不确定性，不代表不同训练 seed 之间的波动。

## 结果与胜者复现

逐回合结果记录实际 checkpoint、权重类型、采样步数、执行长度、seed 列表、环境条件与汇总指标。带有未来力扩散的模型还记录实际未来力采样步数。环境记录中的控制周期来自实际运行环境，评测不自行改变控制频率。

选模汇总保留候选成绩、胜者、两组 seeds 与独立 test 结果。选模结果不会自动改变部署默认选择；复现胜者需要同时指定记录的 checkpoint、raw/EMA 权重、动作采样步数与执行长度。涉及独立未来力采样时，也须保持相应设置。

闭环评测关注环境中的实际任务完成情况；模型的训练目标、动作表示及推理过程见[项目架构](项目架构.md)。远程运行操作见[SSH 服务器训练部署](SSH服务器训练部署.md)。
