# DexMani Policy · 手部动作表示

DQ-RISE 是本地研究适配。SAT/DQ-RISE 统一观测编码器、窗口、flow 与策略训练配方，但 SAT 使用官方结构化关节轨迹动作头，DQ 使用普通 DiTX；两者同时存在动作表示和动作头结构差异，不能作为纯动作表示消融。共享接口见 [项目架构](项目架构.md)，以下命令从仓库根目录、Conda `policy` 环境执行。

| 方法 | 手部坐标与表示 | 默认配置 |
| --- | --- | --- |
| DQ-RISE | normalized 单步手姿 → 16 个 prototype 的连续索引 | [dqrise.yaml](../dexmani_policy/configs/dqrise.yaml) |

SAT 的动作输入保持 `[B,16,19]`，内部转为 19 个长度 16 的关节轨迹 token，按[官方 SAT 固定源码](https://github.com/XiaohanLei/SAT/blob/cd7c0a8877d6090a9a85ebee0ceca961830b3654/sim/sat/model/diffusion/sat.py)拼接轨迹、robot identity 和 joint identity embedding，输出再转回 `[B,16,19]`。本地 metadata 只定义固定 xArm7/XHand 控制顺序：arm 的 robot ID 为 0、joint ID 为 0–6，hand 的 robot ID 为 1、joint ID 为 0–11。它们不是官方多机器人语义编号，也不声明可直接迁移官方预训练权重；不增加 URDF、分组或关节轴 embedding。

VQ 预训练入口使用 `--config` 加 Hydra `key=value`；配置使用固定 `dexmani_policy/configs/` 下的名称或相对子路径，如 `pretrain/hand_prior/vqvae`（可带 `.yaml`）；这是入口约定，不提供配置安全隔离保证。手部直接按 limits 拟合，配置不生成或保存 normalization 标记；训练参数位于独立配置的 `vq_vae`。训练数据须至少组成一个完整 batch，小规模验证需显式减小 batch_size。

实现位于 `training/pretrain/hand_prior/`。其中 `codebook.py` 负责原型构建、PCA 排序和导出。VQ 训练与独立 CLI 共用 `export_codebook()` 读取 Checkpoint 并原子保存码本，返回 `(codebook, metadata)`；`export_codebook.py` 负责命令解析和打印。运行时 `HandStateCodebook` 仅保存固定形状的有序 prototype 表并编解码；`agents/hand_prior/artifacts.py` 独立读写 NPZ，`load_codebook(path, codebook)` 返回 `(metadata, hand_affine)`。NPZ 保存 `sorted_hand_poses`、`hand_normalizer_scale/offset`、`pose_space`、`hand_dim`、`num_groups`、`codebook_size` 和 `metadata_json`；metadata 记录模型结构、动作语义、实际 split、排序方式及选点来源。PCA 排列只用于生成有序原型，learned layer weights 仍参与解码并随 VQ 模型状态保存。

## 数据与准备

数据契约为 `obs[t]_before_action[t]`，动作是 7 arm + 12 hand 的绝对 joint targets，单位 radians；手部顺序为 XHand thumb×3、index×3、middle×2、ring×2、pinky×2。单帧 DQ 码本不依赖 dt 或动作窗口。不自动移位或猜测旧采集语义。

主策略统一默认 `dataset.seed=42`、`dataset.val_ratio=0.1`、最多100个训练回合。VQ-VAE 使用 `pretrain/hand_prior/vqvae` 独立配方，默认 `max_train_episodes=null`，预算、验证与保存规则由预训练自身管理。同源 DQ/VQ 的产物绑定要求两阶段实际 split 一致，因此以下示例显式共用清单；预训练独立运行时无需套用主策略上限。已有 trial 身份时按 trial 分组，不为凑满上限拆分。格式及搬迁规则见 [划分与数据身份](项目架构.md#划分与数据身份)。

```bash
conda activate policy
DATA_ZARR=/path/to/dataset.zarr
HAND_RUN="experiments/hand_spaces/$(date +%Y%m%d_%H%M%S)_${RANDOM}"
SPLIT_PATH=/path/to/episode_split.json
python -m dexmani_policy.datasets.split --zarr-path "$DATA_ZARR" \
  --output "$SPLIT_PATH" --val-ratio 0.1 --seed 42 --max-train-episodes 100
DATA=("zarr_path=$DATA_ZARR" "dataset.split_manifest=$SPLIT_PATH")
```

显式清单保留其 validation 集合，不按 seed 重新划分；超过配置的训练回合上限时报错。无 holdout 的小样本验证，用 `--val-ratio 0` 生成两阶段共用的清单，并将指标标为 train；单 episode 必须如此。

通用 affine 的训练源行总体见 [归一化](项目架构.md#归一化)；DQ 手部 affine 使用下文的 limits 统计。验证复用训练统计并关闭增强。

## DQ-RISE 码本

```bash
python -m dexmani_policy.training.pretrain.hand_prior.vqvae --config pretrain/hand_prior/vqvae \
  "${DATA[@]}" "vq_vae.output_dir=$HAND_RUN/dqrise"
bash scripts/training/train.sh dqrise "${DATA[@]}" \
  initialization.codebook="$HAND_RUN/dqrise/codebook.npz"
```

依据 [DQ-RISE v2 §III](https://arxiv.org/html/2509.17450v2) 和固定代码 [2889d27](https://github.com/rise-policy/DQ-RISE/tree/2889d27fce823288e8dd12ec6e91506b52ed086a)。VQ 训练结束后从已选 best 自动保存 `codebook.npz`，随后直接训练 Policy。`export_codebook` 入口保留为可选的显式重导出工具。默认 `initialization.codebook=null`，新训练须提供匹配产物；来源路径只在 fresh 组装时使用。VQ 参数通过 `vq_vae.*` 覆盖，例如 `vq_vae.kmeans_init=true`；`vq_vae.output_dir` 须为新目录。归一化手部数组直接在主进程加载，无需额外 worker。

预训练通过 `vq_vae.num_groups` 和 `vq_vae.codebook_size` 配置码本结构；Policy 对应使用 `agent.codebook_num_groups` 和 `agent.codebook_size`，两阶段默认分别为 2 和 4。修改尺寸时分别设置两阶段参数；Policy 加载产物时检查结构、手部 affine 和实际 split。主策略配置不包含预训练配方。

预训练直接按 train/val episodes 读取全部真实帧的 12D hand commands，不构造或扫描视觉 Dataset；仅以训练数组分块拟合 `hand` limits，再共用于训练和验证。VQ 固定读取 joint19 的 `action[:,7:19]`，不提供 action_key 选项；实际 hand affine 随码本保存，导出直接消费该 affine。新 Policy 从相同实际 train split 拟合 action，再在最终安装前将导出的 hand affine 写入唯一的 action normalizer 手部子段；运行码本不再复制 affine。验证不参与拟合，horizon/padding 不改变统计总体。

`scripts/pretrain/vqvae.sh [key=value ...]` 直接透传配置覆盖，例如 `task_name=pick_apple_messy`、`zarr_path=/path/to/data.zarr` 和 `vq_vae.output_dir=/path/to/new_run`。未指定数据路径时，路径随最终 `task_name` 解析；未指定输出目录时，预训练入口在 `experiments/vq_hand/<数据集名>/` 下自动创建独立目录。

VQ 量化单步 normalized hand target：encoder/decoder 各 6 个 512D 隐藏层，latent 256；两层 residual quantizer 各 4 code，共 16 个组合。残差减去 detached quantized，训练用 straight-through，commitment 对 code 停梯度，各层按 learned softmax weights 合成。

非 kmeans 初始化使用一致的单位伪计数：`cluster_size=ones(K)`、`embed_avg=embed*cluster_size[:,None]`，避免首批未命中 code 除以接近零的计数而放大。kmeans 使用实际 counts/centers。更换 codebook 后须重训下游 Policy，不替换已训练策略的内嵌码本。

VQ、kmeans、预训练选点和部署表 lookup 的最近邻统一在关闭 autocast 的 FP32 下使用 `cdist(..., compute_mode="donot_use_mm_for_euclid_dist")`，避免内积展开的消减误差及默认 cdist 的矩阵乘法分派改变近重合原型的索引。VQ EMA 用定长 scatter 计数、index_add 累加和替代 one-hot；kmeans 也避免 CUDA bincount 的 host 读取。保留 Laplace smoothing、空簇旧中心和死码替换；浮点累加顺序变化不保证逐位续训。码本算法核对了官方固定版本的 [residual_vq.py](https://github.com/rise-policy/DQ-RISE/blob/2889d27fce823288e8dd12ec6e91506b52ed086a/policy/vqvae_rise/vector_quantize_pytorch/residual_vq.py) 与 [vector_quantize_pytorch.py](https://github.com/rise-policy/DQ-RISE/blob/2889d27fce823288e8dd12ec6e91506b52ed086a/policy/vqvae_rise/vector_quantize_pytorch/vector_quantize_pytorch.py)。

direct 距离优先保证索引数值正确，大潜变量码本可能明显变慢。本次串行复测 RTX 4090、Torch 2.4.1、TF32=False，N256/K4/D256 的距离与 argmin 前向为内积展开 0.033 ms、direct 0.007 ms；N4096/K512/D256 为 0.085 ms、2.670 ms，后者是已接受的精度/效率取舍，不代表整段预训练耗时。VQ、kmeans、预训练选点和部署表 lookup 共用 `codebook_distances` 的 FP32 direct 距离；选点用 `codebook_chunk_size` 将单块 `[N,K]` 距离矩阵限制在 16 MiB，不构造 `[N,K,12]` 中间量。预算至少容纳一行，大表仍可能增加耗时。计时方式见项目架构的 agents 优化依据与验证。

损失为 `3*mean(abs(reconstruction-target)*joint_weight) + 5*sum(commitment)`，前 8 个关节权重 1、后 4 个 0.5；reconstruction MSE 仅作诊断，在 no_grad 下计算。评估/导出统一使用 learned weights → decoder → act_scale → clamp `[-1,1]`，在解码手姿空间做 PCA 排序。

监督标签为最终部署表中最近的 normalized prototype：`s=2*i/(M-1)-1`；解码为 `floor((clamp(s,-1,1)+1)*(M-1)/2+0.5)`，lookup 后逆 action affine。验证仅计算实际选模使用的 lookup_mse，不执行额外重建前向；训练仍记录 reconstruction、commitment 和总 loss。选点使用固定模型 eval/no_grad 的 `lookup_mse=sum_i min_j ||hand_norm_i-prototype_j||²/(N*12)`，不更新 codebook EMA；PCA 排序不改变该误差。

decode 在离散化之前拒绝 NaN/Inf，并在整型转换后截断索引。BF16/FP16 在 K=256/512 的端点可能舍入到 K；后续物理动作有限性检查无法替代离散化前检查。上述检查及截断均保留。

### 窗口与 flow

新训练与 SAT 统一为 `Nobs=2,H=16,C=8`、`pad_before=1,pad_after=7,action_start_index=1`。普通 8 层 DiTX 以共享 dense 观测 `[B,194,256]` 为条件，标准 uniform RectifiedFlow 预测 `[B,16,8]`（7D arm + 1D hand index），默认 10 步均匀 Euler 后再 lookup 为 `[B,16,19]`。第 0 步与历史对齐，`future_actions` 和连续/离散索引均返回原预测 `[1:]`，执行 `[1:9]`。积分过程中不裁剪或取整索引；仅在最终 decode 保留既有离散化。单帧码本与 H/C、padding 或 dt 无关，VQ-VAE 预训练配方不变。恢复严格使用 checkpoint 保存的完整架构、参数和 normalizer，无需原码本文件或初始 DINO 权重。

## 官方实现与本地适配

| 方法 | 重要的本地差异 |
| --- | --- |
| DQ | 策略与 SAT 共用 dense 编码器和 uniform flow，动作头为普通 DiTX；码本预训练不变。本地 VQ `num_layers=6` 计全部隐藏层，导出使用 learned weights（非官方固定 0.5/0.5），按部署 lookup 误差选点 |

## DQ-RISE 训练默认值

训练预算、LR、betas、decay、裁剪与调度以 [策略配置](../dexmani_policy/configs/) 和预训练入口为准。DQ 策略采用与 SAT 相同的 `1e-4` LR、`(0.95,0.999)` betas、`1e-6` decay、cosine/warmup 500、grad norm 1.0 和训练/评测 EMA，100000 updates 是共同本地预算，不宣称最优；DINO 默认冻结，其余 encoder 可训练。`obs_lr` 作用于整个可训练观测编码器，包括可选 LoRA。VQ 预训练及 codebook EMA 独立保留，策略 EMA 不改变码本训练。优化器按有效 update 推进，关闭裁剪仍检查非有限值。SAT/DQ 总 flow MSE 不可直接横向比较，DQ 另关注部署 lookup 重建误差。

## 预训练数据与选点

| 方法 | 有 holdout | 无 holdout | 产物 |
| --- | --- | --- | --- |
| DQ VQ | `val_lookup_mse` | `train_lookup_mse`，标记 train_no_holdout | VQ checkpoint、codebook NPZ |

DQ 的 `hand_data` 只保存动作键，布局/单位由局部产物与输入检查保证；实际身份和划分统一存于 canonical `split_manifest`，预训练与 Policy 直接比较完整 manifest。VQ 训练将完整配方记录在一次 `config.yaml` 中，逐 epoch 保存 `metrics.jsonl`，保留选模标量与不同的 best/last/周期 checkpoint。训练结束导出已选 best 的 NPZ。选点用 normalized MSE，导出读取显式 selection_split/metric，不从 episode 列表推断。

## 加载

| 方法 | 新训练必须匹配 |
| --- | --- |
| DQ | 手部 affine、相同的实际 split，`pose_space=normalized`，码本结构、prototype 布局与有限值 |

独立 VQ 的 `config.yaml` 保存解析后的数据路径、划分参数、实际 split 和预训练配方；checkpoint 保存模型、hand affine、实际 split 与选模指标，不再复制数据配置。

完整 Policy 的 raw/EMA 保存 prototype 表及唯一 action affine，effective_config 保存实际构造配置；推理无需原码本文件或训练数据；resume 严格核对实际 split 与训练状态，并恢复保存的 affine。预训练产物在导入边界校验字段、布局和统计；独立 VQ 预训练不提供完整续训。DQ 新策略默认 EMA；请求不存在的 EMA 会失败。

更换 VQ codebook 后须重训下游 Policy，不能替换已训练 Policy 的内嵌码本。数据重新生成使用新路径，历史产物沿用对应源码。
