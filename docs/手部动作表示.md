# 手部动作表示

SAT、DQ-RISE 和 DexLatent 共享空间观测编码与 Rectified Flow 框架，区别在于如何表示和生成手部动作。三者最终都将内部表示还原为手臂与手部的绝对关节目标。

三者的 RGB–point 编码器默认使用 DINOv3 ViT-S/16，预训练权重位于 `data/pretrained/dinov3-small`。默认 `rgb_backbone_config.tune_mode: freeze`，DINOv3 骨干保持 eval 模式且不更新参数；点云编码、RGB 融合和动作网络继续训练。可显式设置 `lora` 或 `full` 进行微调实验。

新训练使用 `freeze` 或 `lora` 时必须提供 RGB 预训练权重；只有 `full` 模式允许从随机权重训练。恢复和部署直接读取 checkpoint 中的骨干及归一化参数，不依赖原预训练目录。投影诊断工具从同一编码器接口读取 patch 大小，复用确定性 FPS 并随采样点保留原始 RGB，不执行局部特征编码或按坐标反查颜色。

投影诊断的 `summary.json` 用 `valid` 和 `depth_valid` 记录可见中心与有效深度的数量；没有样本的统计量为 `null`。深度误差只统计可见且深度非零的中心。

## 三种表示

| 方法 | 模型生成什么 | 如何还原动作 |
| --- | --- | --- |
| SAT | 按关节组织的整段轨迹 | 还原轨迹排列与关节尺度 |
| DQ-RISE | 手臂目标与连续手姿索引 | 将索引离散化，在固定码本中选择手姿 |
| DexLatent | 手臂目标与连续手部潜表示 | 使用冻结解码器还原手部关节目标 |

## SAT：按关节组织轨迹

SAT 将同一关节在整个动作窗口内的轨迹组织为一个特征单元（token），再联合建模不同关节之间的关系。模型直接在关节表示中学习，不需要独立的手姿先验。

这种组织方式强调一段时间内的关节协同。Flow 学习的是生成过程中的变化方向，输出动作仍是关节目标，而非物理关节速度。

## DQ-RISE：从固定码本选择手姿

DQ-RISE 先用示教手姿训练残差 VQ-VAE，再将解码得到的手姿原型排序，形成固定码本。每个原型代表整只手的一种目标姿态。

策略联合生成手臂动作与连续手姿索引，在生成结束后将索引离散化并查表。在线推理只使用码本，不再运行 VQ-VAE。码本限定了可生成的手姿集合。

在 `policy` 环境、仓库根目录准备码本并启动下游策略：

```bash
python -m dexmani_policy.training.pretrain.hand_prior.vqvae \
  task_name=pick_apple_messy workspace.output_dir=experiments/pretrain/vqvae/run_01
bash scripts/utils/download_pretrained.sh dqrise
bash scripts/training/train.sh dqrise task_name=pick_apple_messy \
  initialization.codebook=experiments/pretrain/vqvae/run_01/codebook.npz
```

预训练结束后自动导出有序姿态表及 hand affine；设置验证回合时从 `best.pt` 导出，否则使用 `last.pt`。码本训练预算由独立配方的 `vq_vae.num_epochs` 控制。

## DexLatent：在连续先验空间生成手姿

DexLatent 使用预训练的 XHand 编码器和解码器，并在策略训练中保持冻结。训练时，编码器将示教手姿转换为连续潜表示；推理时，Flow 生成潜表示，再由解码器还原关节目标。

潜表示是先验学习到的手姿坐标，各维不直接对应关节，也不意味着对手姿进行低维压缩。

## 与整体策略的关系

三者改变了轨迹组织或手部生成坐标，观测仍由共同的空间编码器提供。DQ-RISE 的码本来自本地示教，DexLatent 使用外部冻结先验，比较时需考虑先验来源的差异。

整体数据流见[项目架构](项目架构.md)，策略效果通过[仿真评测](仿真评测机制.md)比较。

码本仅保存排序后的手姿和归一化参数；可以从验证集选出的 best checkpoint 导出，不要求与 last 同步。重新导出使用：

```bash
python -m dexmani_policy.training.pretrain.hand_prior.codebook \
  --checkpoint experiments/pretrain/vqvae/run_01/checkpoints/best.pt \
  --output experiments/pretrain/vqvae/run_01/codebook.npz --overwrite
```
