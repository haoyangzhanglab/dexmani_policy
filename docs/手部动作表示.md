# DexMani_Policy 手部动作表示

DQ-RISE、LAMP 和 Temporal 是本地研究适配，模型、窗口与目标均有差异，不能直接视为纯动作空间消融。通用接口见 [项目架构](项目架构.md)，命令从仓库根目录执行。

## 数据与准备

仅支持当前 SIM/Real 导出时序：`obs[t]` 在 `action[t]` 提交前采集，不使用 `obs_alignment` 或自动移位。要求有限正 `dt`；手部为 XHand thumb×3、index×3、middle×2、ring×2、pinky×2，单位 radians。

正式 baseline 在表示预训练、Policy 和各 seed 间复用 episode 级 held-out manifest，格式见 [划分与数据身份](项目架构.md#划分与数据身份)。缺少真实 episode/trial 身份时重新导出，不补造。smoke 可无 holdout，但不据此报告泛化；比较需记录实际窗口数与 padding 比例。

以下示例统一 joint action 和数据划分，各方法保存独立产物，已有文件默认不覆盖：

```bash
conda activate policy
DATA_ZARR=/path/to/revision.zarr
SPLIT=/path/to/episode_split.json
HAND_RUN="experiments/hand_spaces/$(date +%Y%m%d_%H%M%S)_${RANDOM}"
DATA=("zarr_path=$DATA_ZARR" "dataset.split_manifest=$SPLIT"
      dataset.max_train_episodes=null dataset.val_ratio=0)
```

## DQ-RISE 码本

```bash
VQ_DATA=()
for item in "${DATA[@]}"; do VQ_DATA+=(--policy-override "$item"); done
python -m dexmani_policy.training.pretrain.hand_prior.vqvae \
  --policy-config dexmani_policy/configs/dqrise.yaml \
  "${VQ_DATA[@]}" --policy-override action_key=action \
  --output_dir "$HAND_RUN/dqrise"
python -m dexmani_policy.training.pretrain.hand_prior.export_codebook \
  --checkpoint "$HAND_RUN/dqrise/vqvae_hand_best.pt" \
  --output "$HAND_RUN/dqrise/codebook.npz"
bash scripts/training/train.sh dqrise "${DATA[@]}" action_key=action \
  codebook_path="$HAND_RUN/dqrise/codebook.npz"
```

配置默认 EEF `9+12`，示例显式改为 joint `7+12`。便捷入口为 `bash scripts/pretrain/vqvae.sh <task> [VQ options...]`。

采用 [DQ-RISE v1 §III](https://arxiv.org/html/2509.17450v1) 的单帧 residual VQ、组合原型、PCA 排序和单标量 lookup，默认 2 组×4 code，共 16 原型。训练标签为部署表的最近 normalized prototype，`s=2*i/(M-1)-1`；解码取 `floor((clamp(s,-1,1)+1)*(M-1)/2+0.5)` 查表。运行时直接存储 normalized prototypes，在同一空间计算平方欧氏距离并查表，再逆 action affine 得到物理动作。

本仓使用 weighted L1 reconstruction 与 EMA commitment；[固定官方训练代码](https://github.com/rise-policy/DQ-RISE/blob/2889d27fce823288e8dd12ec6e91506b52ed086a/train_dqrise.py)同样按原型 NN 标注。本仓训练/导出均使用学习到的 softmax layer weights，区别于[官方导出](https://github.com/rise-policy/DQ-RISE/blob/2889d27fce823288e8dd12ec6e91506b52ed086a/eval_vqvae.py)的两 code 平均。VQ 数据取有效训练窗口引用的唯一 action 源行，验证复用训练统计。

## LAMP 历史先验

```bash
python -m dexmani_policy.training.pretrain.hand_prior.lamp --config lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
bash scripts/training/train.sh lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
```

产物默认写入 `agent.prior_path`（由 `lamp.prior_path` 插值）；使用 `--output` 时需同步 Policy 路径。

对应 [LAMP v1 Eq.1–6](https://arxiv.org/html/2607.06323v1)：H=Nobs=C=1，K=8 为严格过去的执行命令历史，不足时用初始实测 q0 补齐。prior 预训练以重参数采样重建下一命令并加 Gaussian KL；Policy 冻结 E/D，以观测和 `[mu,std]` 回归 arm 与 delta_z，不采样 prior：

```text
hand_hat_norm = D(mu + delta_z)
L = mean(arm_norm_error²) + mean(hand_prior_norm_error²)
    + 1e-3*mean_batch(sum_latent(delta_z²))
```

arm 用 Policy affine，hand 用匹配的 prior affine，各逆变换一次。冻结 decoder 仍保留对 delta_z 的梯度。[固定官方 BC](https://github.com/dex-lamp/LAMP/blob/0467ba3504e0d199727a0586ba525c5fe14f8138/imitation_learning/behavior_clone/scripts/train_jax.py)使用 decoded drift，本仓采用论文 latent L2；12→2、19 维 proprio 和 Sparse3D 属于本地适配，不含 RL。

## Temporal hand VAE

```bash
python -m dexmani_policy.training.pretrain.hand_prior.temporal_vae --config temporal_codec_flow "${DATA[@]}" \
  codec.path="$HAND_RUN/temporal/codec.pt"
bash scripts/training/train.sh temporal_codec_flow "${DATA[@]}" \
  codec.path="$HAND_RUN/temporal/codec.pt"
```

产物默认写入 `agent.codec_path`（由 `codec.path` 插值）。采用 [Temporal v1 §3、Appendix A/B](https://arxiv.org/html/2609.19666v1) 的 q0 条件双向时序 VAE、差分重建、posterior mean 和 latent FM，保留 H=16、Nobs=2、C=8、12→9。本仓单手和视觉配方为适配；[Wuji 固定发布代码](https://github.com/wuji-technology/wuji-openpi/tree/be6b32540546fb4fdd274f5cc86a7f9a67148a4c)未提供该 codec，不能称完整系统的逐行复现。

`r=(hand_chunk-q0-mean)/std`，q0 是 query 源帧未增强实测值，由 `action_context.hand_reference` 提供；统计按训练窗口计入重叠与 padding。预训练的位置/一阶/二阶差分 weighted Huber 权重为 1/0.2/0.05，关节权重由 `codec.joint_weights` 控制。差分匹配目标运动，不作趋零平滑。

Policy 在线用冻结 encoder mean 作 FM 标签：`s~0.999*Beta(1,1.5)`、`x_s=(1-s)*noise+s*target`、`v=target-noise`，clean estimate 为 `x_s+(1-s)*v_hat`。损失为 `L_arm_FM+0.25*L_latent_FM+0.75*L_decoded`，各组全 H 取 mean；decoded MSE 仅在 standardized relative 空间，physical MAE/RMSE 只诊断，冻结 D 保留梯度。

窗口为 `a[t-1:t+15]`，q0=q_t；完整解码后执行 `[1:9]`，整段 q0 固定，不截断双向 decoder、不逐帧重锚定。物理解码仅一次 `decoded*std+mean+q0`；同源帧可有不同 q0，不建逐帧 latent cache。

## 预训练数据与选点

| 方法 | 有 holdout | 无 holdout | 当前产物 |
| --- | --- | --- | --- |
| DQ-RISE VQ | 按 `val_mse` | 按 `train_mse`，可导出 | VQ checkpoint v5、codebook NPZ v5 (`pose_space=normalized`) |
| LAMP | deterministic prior-mean MSE | 最终合格步骤 | `lamp_prior.v3` |
| Temporal | physical MAE | 最终合格步骤 | `temporal_hand_codec.v2` |

LAMP 默认 20k steps、2k warmup、beta=1e-3；Temporal 默认 30k、4k 零 KL + 4k ramp、beta=3e-4。仅在 KL 达正目标后选点，schedule 不足时训练前报错；无 holdout 标记 `final_no_holdout`。选点信息保存在 selection，指标和调度参数留在 metrics/train_args。

`hand_data` 保存 revision、episode 身份/边界、train/val 集合、动作键、dt、窗口/历史长度及样本计数。它不计算内容哈希，数据改变需更新 revision。VQ 的 `codebook_diagnostics.json` 记录实际 NN→lookup 的 normalized/physical 误差、利用率与跳变；不以重建误差替代 lookup 误差，训练指标保留在原 checkpoint。

## 加载与兼容

三个阶段共用配置/窗口校验和数据覆盖。Fresh training 核对 `hand_data` 与坐标：DQ/LAMP 核对手部 affine，Temporal 用内嵌相对统计；观测归一化可在 encoder 约束内另选，Sparse3D 点云仍须 `identity`。

strict resume 用 checkpoint 内嵌表示并重新核对保存的 `hand_data`；raw/EMA 均内嵌表示和 normalizer，独立推理无需原产物或训练数据。

DQ codebook 可读取合法 v4 `affine_raw` NPZ，使用文件内实际 `hand_min/max` 一次性转换为 normalized，保留原型行序和 `pca_permutation`；后续只保存 v5。NPZ 与旧 DQ Policy raw/EMA state 共用加载边界的一次转换和校验，内存中仅保留 normalized buffer，保持 strict load 与 normalizer 一致性检查，无需外部 VQ 文件。统一正仿射下最近邻定义不变，极近距离平局可能受浮点舍入影响。其他旧手部产物或缺少 `hand_data` 的手部训练恢复需历史源码或重新准备；视觉修改不要求重训仍匹配坐标的手部表示。

LAMP/Temporal 仅支持 sync，拒绝 prefix/delay。LAMP 的 `action_context.hand_history` 由执行端维护，`predict` 不更新历史；格式与执行职责见 [部署边界](项目架构.md#部署边界)，真机闭环 **NOT VERIFIED**。

预训练与导出入口位于 `training/pretrain/hand_prior/`，表示模型位于 `agents/hand_prior/`，历史/q0 Dataset 位于 `datasets/hand_prior/`，均相对于 `dexmani_policy/`。
