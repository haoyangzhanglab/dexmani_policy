# DexMani_Policy 手部动作表示

DQ-RISE、LAMP 和 LatentFlow 是本地研究适配，观测、窗口及目标不同，不能直接视为纯动作空间消融。共享接口见 [项目架构](项目架构.md)，以下命令从仓库根目录、Conda `policy` 环境执行。

| 方法 | 手部坐标与表示 | 默认配置 |
| --- | --- | --- |
| DQ-RISE | normalized 单步手姿 → 16 个 prototype 的连续索引 | [dqrise.yaml](../dexmani_policy/configs/dqrise.yaml) |
| LAMP | raw radians 历史 → prior latent offset → 单步手姿 | [lamp.yaml](../dexmani_policy/configs/lamp.yaml) |
| LatentFlow / HandVAE | query q0 的 relative command → chunk latent | [latent_flow.yaml](../dexmani_policy/configs/latent_flow.yaml)、[hand_vae.yaml](../dexmani_policy/configs/hand_vae.yaml) |

## 数据与准备

数据契约为 `obs[t]_before_action[t]`，动作是 7 arm + 12 hand 的绝对 joint targets，单位 radians；手部顺序为 XHand thumb×3、index×3、middle×2、ring×2、pinky×2。`dt` 须有限且为正，不自动移位或猜测旧采集语义。

DQ/LAMP 默认 episode 级 9:1 划分、无训练 episode 截断。预训练和 Policy 必须复用同一 manifest；已有 trial 身份时校验 trial 不跨 split，无身份时只记录 episode 索引、路径和边界。格式及搬迁规则见 [划分与数据身份](项目架构.md#划分与数据身份)。

```bash
conda activate policy
DATA_ZARR=/path/to/dataset.zarr
SPLIT=/path/to/episode_split.json
# 首次生成；已有清单直接复用，生成入口拒绝覆盖。
python -m dexmani_policy.datasets.common.episode_split \
  --zarr-path "$DATA_ZARR" --output "$SPLIT" --val-ratio 0.1 --seed 42
HAND_RUN="experiments/hand_spaces/$(date +%Y%m%d_%H%M%S)_${RANDOM}"
DATA=("zarr_path=$DATA_ZARR" "dataset.split_manifest=$SPLIT"
      dataset.max_train_episodes=null dataset.val_ratio=0)
```

manifest 已定义最终集合，加载时 `val_ratio=0` 不会清空其中的 validation。子集用生成入口的 `--max-train-episodes` 定义；无 holdout smoke 用 `--val-ratio 0` 并将指标标为 train。路径绑定的索引清单不能自动重映射。

通用 affine 的训练源行总体见 [归一化](项目架构.md#归一化)；手部 codec 使用下文专用统计。验证复用训练统计并关闭增强。

## DQ-RISE 码本

```bash
VQ_DATA=()
for item in "${DATA[@]}"; do VQ_DATA+=(--policy-override "$item"); done
python -m dexmani_policy.training.pretrain.hand_prior.vqvae \
  --policy-config dexmani_policy/configs/dqrise.yaml \
  "${VQ_DATA[@]}" --output_dir "$HAND_RUN/dqrise"
python -m dexmani_policy.training.pretrain.hand_prior.export_codebook \
  --checkpoint "$HAND_RUN/dqrise/vqvae_hand_best.pt" \
  --output "$HAND_RUN/dqrise/codebook.npz"
bash scripts/training/train.sh dqrise "${DATA[@]}" \
  codebook_path="$HAND_RUN/dqrise/codebook.npz"
```

依据 [DQ-RISE v2 §III](https://arxiv.org/html/2509.17450v2) 和固定代码 [2889d27](https://github.com/rise-policy/DQ-RISE/tree/2889d27fce823288e8dd12ec6e91506b52ed086a)。默认 `codebook_path=null`，新训练须提供匹配产物。VQ 布尔 CLI 使用 `--kmeans_init` / `--no-kmeans_init`。

VQ 量化单步 normalized hand target：encoder/decoder 各 6 个 512D 隐藏层，latent 256；两层 residual quantizer 各 4 code，共 16 个组合。残差减去 detached quantized，训练用 straight-through，commitment 对 code 停梯度，各层按 learned softmax weights 合成。

损失为 `3*mean(abs(reconstruction-target)*joint_weight) + 5*sum(commitment)`，前 8 个关节权重 1、后 4 个 0.5；reconstruction MSE 仅作诊断。评估/导出统一使用 learned weights → decoder → act_scale → clamp `[-1,1]`，在解码手姿空间做 PCA 排序。

监督标签为最终部署表中最近的 normalized prototype：`s=2*i/(M-1)-1`；解码为 `floor((clamp(s,-1,1)+1)*(M-1)/2+0.5)`，lookup 后逆 action affine。选点使用固定模型 eval/no_grad 的 `lookup_mse=sum_i min_j ||hand_norm_i-prototype_j||²/(N*12)`，不更新 codebook EMA；PCA 排序不改变该误差。

### 窗口与 diffusion

默认 `Nobs=1,H=20,C=16`。UNet/DDIM 生成 `[B,20,8]` 的 7D arm+1D hand index，lookup 得 `[B,20,19]`，执行 `[0:16]`。`pad_before=0,pad_after=15`，末端动作重复 padding，不额外移位。DDIM 为 100 training timesteps、20 denoising steps、epsilon prediction、squared-cosine；官方脚本的 `num_inference_step=16` 是重新查询间隔。

SAT 使用 `Nobs=2,H=16,C=8`；两者共享 Sparse3D global 编码结构，但时间输入和融合宽度不同，DQ 条件为 256D。其余网络参数以配置为准。

## LAMP 历史先验

```bash
python -m dexmani_policy.training.pretrain.hand_prior.lamp --config lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
bash scripts/training/train.sh lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
```

依据 [LAMP v1](https://arxiv.org/html/2607.06323v1) 和固定代码 [0467ba3](https://github.com/dex-lamp/LAMP/tree/0467ba3504e0d199727a0586ba525c5fe14f8138)，实现 prior 预训练与 BC。产物默认写入 `agent.prior_path`，显式 `--output` 需同步 Policy 路径。

历史为 `action[t-8:t]`，目标为 `action[t]`，H=Nobs=C=1。episode 初始用实测手姿补齐，在线仅追加实际下发命令，每个 episode 清空历史。prior encoder 为 `flatten(8×12) → 256 SiLU → 256 SiLU → mu/log_var`，decoder 为 `2 → 256 SiLU → 256 SiLU → 12`，只接收 z。预训练重参数采样，损失为 raw hand MSE 加 beta×KL，KL 对 batch/latent 取 mean。

BC 冻结 prior，将 `[mu,log_var]` 经可训练 `4→128 ReLU→128 ReLU` 与观测条件拼接，ReLU head 输出 7D arm 和 2D latent offset：

```text
arm_pred, delta_z = head(condition)
hand_pred = D(mu + delta_z)
loss = mean((arm_pred-arm_target)^2)
     + hand_loss_weight * mean((hand_pred-hand_target)^2)
     + drift_reg_weight * mean((hand_pred-stopgrad(D(mu)))^2)
```

两个权重默认为 1。arm、hand、history、重建和 drift 均为物理 radians，action normalization 为 identity；无额外 hand affine、sigma 倍乘或 latent-L2 分支。decoder/损失保持 FP32，预测分支向 offset 反传，参考分支 no_grad；不增加 tanh、限位损失或训练硬裁剪。`loss_decoded_hand` 是 raw hand MSE，`offset_rms` 仅诊断 latent offset。

prior/BC 历史噪声分别为 0.01/0.10 radians；BC 按 Policy.training 控制。joint_state 经训练源行 Gaussian 标准化后，仅前 7 维 arm 加 std=0.10 噪声，measured hand 不加噪，Dataset 不重复叠加。扰动只改输入副本，验证/推理关闭，std=0 不消费 RNG。

prior 正常训练 shuffle 后丢尾批；不足一个 batch 的小数据保留单个部分批次并记录实际大小，验证始终保留尾批。

## 官方实现与本地适配

| 项目 | 本地选择 |
| --- | --- |
| 观测与执行 | 保留 Sparse3D、proprio、点云处理、同步/runner/限位接口，不移植官方真机或 temporal ensemble |
| DQ 深度 | 官方 shell 的 5 层另有输入隐藏层，本地 `num_layers=6` 表示隐藏层总数 |
| DQ 导出 | 训练/导出统一 learned weights，替代官方导出的固定 0.5/0.5；按部署 lookup 选点 |
| LAMP 条件与正则 | 采用代码的 log_var、ReLU head 和 decoded drift；论文 sigma 特征/latent-offset L2 不视为等价实现 |
| LAMP 时序与配方 | 官方 history 含 t、target 为 t+1，本地使用严格过去命令；BC 采用示例脚本与 CLI 合成的 LR=1e-4、warmup=1000 |
| LAMP 选点 | KL warmup 后按 deterministic prior-mean validation MSE，属于本地部署导向改进 |

## DQ/LAMP 训练默认值

| 阶段 | batch / 预算 | AdamW lr / betas / decay | 调度、裁剪 |
| --- | --- | --- | --- |
| DQ VQ | 256 / 1500 epochs | 3e-4 / (0.95,0.999) / 1e-6 | cosine，warmup 150，关闭裁剪 |
| DQ Policy | 128 / 100000 updates | 3e-4 / (0.9,0.999) / 1e-6 | cosine，warmup 2000，关闭裁剪 |
| LAMP prior | 256 / 20000 updates | 2e-3 / (0.9,0.999) / 1e-4 | min_lr=1e-5，warmup 500，clip 1；beta=1e-3，KL warmup 2000 |
| LAMP BC | 128 / 20000 updates | 1e-4 / (0.9,0.999) / 1e-4 | min_lr=1e-6，warmup 1000，head/backbone 各 clip 1 |

DQ 的 100000 updates 是本地预算，DDP 为 32×4。DQ/LAMP 参数组包括 bias 的 decay；LAMP 的 head 裁剪组含动作头/prior-feature/proprio，backbone 为 Sparse3D。观测 encoder 从头训练，obs_lr 默认分别为 3e-4/1e-4。

两种 Policy 默认使用 raw model，DQ codebook EMA 独立保留。调度按 optimizer update 推进；LAMP LR warmup 在 update 0 为零、W−1 到 peak，W 开始 cosine，KL 到目标后才允许选点。DQ 使用 diffusers cosine/warmup；关闭裁剪仍检查非有限值。

## LatentFlow 与 HandVAE

本地实现适配 [论文 Step 1/2 与 Appendix A/B.1/B.2](https://arxiv.org/html/2609.19666v1)，保留单臂 7+12 DoF、Sparse3D、现有增强和从头训练的 DiTX；不包含 π₀.₅、DAgger 或在线 RL，不能外推为预训练 VLA 的收敛表现。

### 数据和坐标契约

默认 `H=32,Nobs=2,C=25`，query 为 t：`obs=[t-1,t]`、`q0=state[t]`、`action=command[t:t+H]`。Dataset 返回绝对 `[H,19]` command，reference_state 在观测增强前复制；推理省略 context 时取最新原始 joint_state，整段 chunk 共用一个 q0。

仅采样 H 帧真实未来动作完整的窗口；历史不足补首帧，未来不补帧、不跨 episode。完整生成并双向解码 H 后执行 `[0:C]`，`1<=C<=H`；不建逐源帧 latent cache。

| 分量 | 训练与解码 |
| --- | --- |
| arm | `command_arm-q0_arm` 使用训练窗口拟合的 relative affine；逆 affine 后加一次 q0 |
| hand | 仅用 codec 的 `r=(command_hand-q0_hand-mean)/std`；解码为 `r*std+mean+q0`，不经过 action affine |

最终输出始终是绝对 19D command。`data_semantics` 声明关节顺序、radians、绝对 command、obs-before-action 和 query reference，冲突时报错；缺少 Zarr 声明时标记 `config_declaration`，不视为独立的采集时序证明。dt 来自数据，不假定频率或重采样；时长解释见 [执行时长对照](仿真评测机制.md#latentflow-执行时长对照)。

### 独立 HandVAE 预训练

HandVAE 只消费 hand command、query hand state、episode 和语义/时间信息，不加载视觉、不按成功标签筛数据。可使用独立同构语料；同源数据须共享 holdout，训练子集及窗口资格可不同。来源用 source_id 与实际 episode 集合记录，有稳定 episode_ids 时按 ID 对齐；复制件应保留 source_id，路径或数量不同不能证明独立。

默认 codec split/模型 seed 均为 0、90/10、不截断训练 episode；同源 Policy split seed=0、最多 80 个训练 episode，模型 seed=42 独立。显式 manifest 仍定义最终集合，同源分别生成的 codec/Policy 清单须有相同验证集合。

```bash
python -m dexmani_policy.training.pretrain.hand_prior.hand_vae --config hand_vae \
  zarr_path=robot_data/pick_apple_messy.zarr \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
```

更换语料修改本命令的 zarr_path，再将 codec 路径传给 Policy；不继承上文 DQ/LAMP 的 DATA 数组或 Policy 的 80-episode 预算。改变 latent_dim 须重新训练匹配的 codec 和 Policy，不能直接替换旧 checkpoint。

模型使用 q0 token、固定 H 的时间位置参数和逐时刻 Gaussian posterior；默认 latent_dim=9、每侧 width=128、3 层、4 heads。预训练重参数采样，评估与策略标签使用 posterior mean。pre-norm、GELU、末端 LayerNorm 及具体 loss reduction 是本地选择，不声称已由作者实现确认。

统计仅来自训练窗口，每个窗口保留自己的 q0，重叠帧重复计入；std 用 population moments，下限 `1e-6`。位置/一阶/二阶差分 weighted Huber 的阈值为 1，系数为 1/0.2/0.05；thumb/index/middle 权重 1，ring/pinky 为 0.5，只乘分子，分母为 batch×有效帧数×关节数。差分匹配示范运动，KL 为 batch/time/latent mean。

默认训练 30k updates、完整 batch=4096、AdamW LR=3e-4、decay=1e-4、cosine。KL 前 4000 updates 为零，随后 4000 线性到 3e-4。必须有有效 holdout；每 1000 updates 及最终步骤按 posterior-mean physical MAE 选最低值，平局保留较早权重。所有评估点均可选，不设 KL 门槛、不早停；已有输出默认拒绝覆盖。

`codec.pt` 保存结构、统计、来源、选中 step/beta 和 completed_updates。二者须区分：`step=1000,beta=0,completed_updates=30000` 表示落盘的是第 1000 步权重，整次运行完成 30k；beta=0 不构成加载错误。真实质量需重建保存的验证集，用 `training.pretrain.hand_prior.hand_vae.evaluate` 报告 physical MAE（radians）及 KL；较小 MAE 或非零 KL 不能单独证明 latent 有效或无 collapse。

### 双空间 flow 和策略训练

target 为 `[normalized_relative_arm,mu]`，冻结 encoder 在线以 FP32/no_grad 产生 μ，不采样或白化。`s~0.999*Beta(1,1.5)`，`x_s=(1-s)*noise+s*target`，速度目标为 `target-noise`，clean estimate 为 `x_s+(1-s)*v_hat`；时间方向与论文相反但自洽。

`L=L_arm_FM+0.25*L_latent_FM+0.75*L_decoded`，每项按自身 batch/time/coordinate mean。decoded MSE 对比真实示范的 standardized relative hand，冻结 decoder 保留向预测 latent 的梯度，Policy.train 后 codec 仍 eval。`decoded_loss_weight=0` 跳过 decoder 及相关诊断；`one_step_denoising_hand_mae/rmse` 含示范信息，完整生成指标为显式采样评估的 `sampled_hand_*`。推理用 10 步 Euler。

默认 30k updates、global batch=64、AdamW betas=(0.9,0.95)、eps=1e-8、decay=1e-10，bias/norm 等不 decay；主干/encoder peak LR=5e-5、warmup=1000、cosine_min_lr ratio=0.1、global clip=1。EMA 从首次 update 起固定 0.99。FP32 主参数配 BF16 autocast，codec 始终 FP32，设备/dtype 边界由调用者管理；物理逆变换共用 `HandVAE.denormalize_actions`。

```bash
# 单卡 64×1×1
bash scripts/training/train.sh latent_flow \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 四卡 16×4×1
bash scripts/training/train_ddp.sh latent_flow '+training.num_gpus=4' \
  dataloader.batch_size=16 training.loop.gradient_accumulation_steps=1 \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 只限制本次短跑，不改总预算
bash scripts/training/train.sh latent_flow '+max_updates=4' workspace.wandb_cfg=null \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 恢复完整策略不要求原 codec 文件继续存在
bash scripts/training/train.sh latent_flow '+resume_from=experiments/latent_flow/<task>/<run>'
bash scripts/eval/eval_pipeline.sh latent_flow <task> <run> eval.seed=1024 eval.episodes=70
```

batch 配置为每卡数；日志区分 nominal global batch、累积尾组实际 batch 和处理窗口数。关节损失权重只在 HandVAE 配置/产物中声明。搬迁与恢复限制见 [完整恢复边界](项目架构.md#完整恢复边界)。

## 预训练数据与选点

| 方法 | 有 holdout | 无 holdout | 产物 |
| --- | --- | --- | --- |
| DQ VQ | `val_lookup_mse` | `train_lookup_mse`，标记 train_no_holdout | VQ checkpoint、codebook NPZ |
| LAMP | KL 达目标后的 deterministic prior-mean MSE | 最终合格步骤 | prior checkpoint |
| HandVAE | 首次计划评估起的 posterior-mean physical MAE | 拒绝训练 | codec.pt |

`hand_data` 保存来源、episode 身份/边界、划分、动作键、dt、窗口/历史和计数。VQ 的 `codebook_diagnostics.json` 记录 NN→lookup 的 normalized/physical 误差、利用率和跳变；选点用 normalized MSE，导出读取显式 selection_split/metric，不从 episode 列表推断。

## 加载

| 方法 | 新训练必须匹配 |
| --- | --- |
| DQ | 手部 affine、共享 manifest，`pose_space=normalized`，prototype 布局、pca_permutation 与有限值 |
| LAMP | `coordinate_space=raw_joint_targets_radians`、关节顺序、架构和共享 manifest |
| LatentFlow | codec 结构、H、顺序/单位/q0/时间语义、dt（相对容差 1e-6）及来源/holdout；语料规模可不同 |

完整 Policy 的 raw/EMA 内嵌表示权重和统计，effective_config 保存 metadata；推理无需原表示文件或训练数据，resume 仍严格核对数据配方与训练状态。预训练产物严格校验当前字段、权重、统计和 ready 状态，不补齐旧格式；VQ/LAMP/HandVAE 独立预训练均不提供完整续训。DQ/LAMP 默认 raw，请求不存在的 EMA 会失败。

更换 VQ codebook 后须重训下游 Policy，不能替换已训练 Policy 的内嵌码本。数据重新生成使用新路径，历史产物沿用对应源码。

LAMP/LatentFlow 仅 sync，拒绝 prefix/delay；历史由执行端维护，格式见 [部署边界](项目架构.md#部署边界)，真机闭环 **NOT VERIFIED**。
