# DexMani Policy · 手部动作表示

DQ-RISE、LAMP 和 LatentFlow 是本地研究适配，观测、窗口及目标不同，不能直接视为纯动作空间消融。共享接口见 [项目架构](项目架构.md)，以下命令从仓库根目录、Conda `policy` 环境执行。

| 方法 | 手部坐标与表示 | 默认配置 |
| --- | --- | --- |
| DQ-RISE | normalized 单步手姿 → 16 个 prototype 的连续索引 | [dqrise.yaml](../dexmani_policy/configs/dqrise.yaml) |
| LAMP | raw radians 历史 → prior latent offset → 单步手姿 | [lamp.yaml](../dexmani_policy/configs/lamp.yaml) |
| LatentFlow / HandVAE | query q0 的 relative command → chunk latent | [latent_flow.yaml](../dexmani_policy/configs/latent_flow.yaml)、[hand_vae.yaml](../dexmani_policy/configs/pretrain/hand_prior/hand_vae.yaml) |

三个预训练入口均使用 `--config` 加 Hydra `key=value`；VQ 参数位于 `vq_vae`，LAMP 参数位于 `prior_training`，HandVAE 参数位于 `training` 和 `codec`。训练数据须至少组成一个完整 batch，小规模验证需显式减小 batch_size。

实现位于 `training/pretrain/hand_prior/`。其中 `codebook.py` 负责原型构建、PCA 排序、导出和部署诊断。VQ 训练与独立 CLI 共用 `export_codebook()` 读取 Checkpoint 并原子保存码本；`export_codebook.py` 负责命令解析和打印，训练继续使用返回的码本进行部署诊断。

## 数据与准备

数据契约为 `obs[t]_before_action[t]`，动作是 7 arm + 12 hand 的绝对 joint targets，单位 radians；手部顺序为 XHand thumb×3、index×3、middle×2、ring×2、pinky×2。LAMP 和 HandVAE/LatentFlow 的 `dt` 须有限且为正；单帧 DQ 码本不依赖 dt 或动作窗口。不自动移位或猜测旧采集语义。

主策略统一默认 `dataset.seed=42`、`dataset.val_ratio=0.1`、最多100个训练回合。VQ-VAE 和 LAMP prior 使用 `pretrain/hand_prior/` 薄配置，复用模型与数据定义，但默认 `max_train_episodes=null`，保留模块自己的预算、验证与保存规则。同源 DQ/LAMP 的产物绑定要求两阶段实际 split 一致，因此以下示例显式共用清单；预训练独立运行时无需套用主策略上限。已有 trial 身份时按 trial 分组，不为凑满上限拆分。格式及搬迁规则见 [划分与数据身份](项目架构.md#划分与数据身份)。

```bash
conda activate policy
DATA_ZARR=/path/to/dataset.zarr
HAND_RUN="experiments/hand_spaces/$(date +%Y%m%d_%H%M%S)_${RANDOM}"
SPLIT_PATH=/path/to/episode_split.json
python -m dexmani_policy.datasets.tools.make_split --zarr-path "$DATA_ZARR" \
  --output "$SPLIT_PATH" --val-ratio 0.1 --seed 42 --max-train-episodes 100
DATA=("zarr_path=$DATA_ZARR" "dataset.split_manifest=$SPLIT_PATH")
```

显式清单保留其 validation 集合，不按 seed 重新划分；超过配置的训练回合上限时报错。无 holdout 的小样本验证，用 `--val-ratio 0` 生成两阶段共用的清单，并将指标标为 train；单 episode 必须如此。

通用 affine 的训练源行总体见 [归一化](项目架构.md#归一化)；手部 codec 使用下文专用统计。验证复用训练统计并关闭增强。

## DQ-RISE 码本

```bash
python -m dexmani_policy.training.pretrain.hand_prior.vqvae --config pretrain/hand_prior/vqvae \
  "${DATA[@]}" "vq_vae.output_dir=$HAND_RUN/dqrise"
bash scripts/training/train.sh dqrise "${DATA[@]}" \
  codebook_path="$HAND_RUN/dqrise/codebook.npz"
```

依据 [DQ-RISE v2 §III](https://arxiv.org/html/2509.17450v2) 和固定代码 [2889d27](https://github.com/rise-policy/DQ-RISE/tree/2889d27fce823288e8dd12ec6e91506b52ed086a)。VQ 训练结束后从已选 best 自动保存 `codebook.npz`，随后直接训练 Policy。`export_codebook` 入口保留为可选的显式重导出工具。默认 `codebook_path=null`，新训练须提供匹配产物。VQ 参数通过 `vq_vae.*` 覆盖，例如 `vq_vae.kmeans_init=true`；`vq_vae.output_dir` 须为新目录。归一化手部数组直接在主进程加载，无需额外 worker。

`agent.codebook_num_groups` 和 `agent.codebook_size` 分别引用 `vq_vae.num_groups` 和 `vq_vae.codebook_size`；调整码本尺寸时覆盖 `vq_vae` 中的值，预训练和 Policy 使用同一组设置。

预训练直接按 train/val episodes 读取全部真实帧的 12D hand commands，不构造或扫描视觉 Dataset；仅以训练数组分块拟合 `hand` limits，再共用于训练和验证。它与新 Policy 对训练 episodes 全部 19D action 拟合后取手部 affine 数值一致；验证不参与拟合，horizon/padding 不改变统计总体。

`scripts/pretrain/vqvae.sh [task_name] [key=value ...]` 使用相同的配置与预训练入口。可用 `TASK_NAME`、`ZARR_PATH`、`OUTPUT_DIR` 环境变量设置任务、数据路径和输出目录；位置参数优先于 `TASK_NAME`，`key=value` 覆盖优先级最高。未指定数据路径时，路径随最终 `task_name` 解析；未指定输出目录时，预训练入口在 `experiments/vq_hand/<数据集名>/` 下自动创建独立目录。

VQ 量化单步 normalized hand target：encoder/decoder 各 6 个 512D 隐藏层，latent 256；两层 residual quantizer 各 4 code，共 16 个组合。残差减去 detached quantized，训练用 straight-through，commitment 对 code 停梯度，各层按 learned softmax weights 合成。

非 kmeans 初始化使用一致的单位伪计数：`cluster_size=ones(K)`、`embed_avg=embed*cluster_size[:,None]`，避免首批未命中 code 除以接近零的计数而放大。kmeans 使用实际 counts/centers。更换 codebook 后须重训下游 Policy，不替换已训练策略的内嵌码本。

损失为 `3*mean(abs(reconstruction-target)*joint_weight) + 5*sum(commitment)`，前 8 个关节权重 1、后 4 个 0.5；reconstruction MSE 仅作诊断，在 no_grad 下计算。评估/导出统一使用 learned weights → decoder → act_scale → clamp `[-1,1]`，在解码手姿空间做 PCA 排序。

监督标签为最终部署表中最近的 normalized prototype：`s=2*i/(M-1)-1`；解码为 `floor((clamp(s,-1,1)+1)*(M-1)/2+0.5)`，lookup 后逆 action affine。选点使用固定模型 eval/no_grad 的 `lookup_mse=sum_i min_j ||hand_norm_i-prototype_j||²/(N*12)`，不更新 codebook EMA；PCA 排序不改变该误差。

### 窗口与 diffusion

默认 `Nobs=1,H=20,C=16`。UNet/DDIM 预测 `[B,20,8]`（7D arm + 1D hand index），lookup 为 `[B,20,19]` 并执行前 16 帧。`pad_before=0,pad_after=C-1`（默认 15），只在 episode 末端重复 padding、不移位。H/C 可独立实验，仍要求 `Nobs=1`、合法动作窗口和 UNet 长度；单帧码本不与 H/C、padding 或 dt 绑定。DDIM 为 100 training timesteps、20 denoising steps、epsilon prediction、squared-cosine；官方 `num_inference_step=16` 指重新查询间隔，不是本地 NFE。SAT 的 `Nobs=2,H=16,C=8`，时间输入/融合不同；其余参数见配置。

## LAMP 历史先验

```bash
python -m dexmani_policy.training.pretrain.hand_prior.lamp --config pretrain/hand_prior/lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
bash scripts/training/train.sh lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
```

依据 [LAMP v1](https://arxiv.org/html/2607.06323v1) 和固定代码 [0467ba3](https://github.com/dex-lamp/LAMP/tree/0467ba3504e0d199727a0586ba525c5fe14f8138)，实现 prior 预训练与 BC。产物写入 `agent.prior_path`，通过 `lamp.prior_path=...` 同时指定预训练和 Policy 路径。优化参数通过 `prior_training.*` 覆盖，例如 `prior_training.steps=20000`。

历史为 `action[t-8:t]`，目标为 `action[t]`，H=Nobs=C=1。episode 初始用实测手姿补齐，在线仅追加实际下发命令，每个 episode 清空历史。prior encoder 为 `flatten(8×12) → 256 SiLU → 256 SiLU → mu/log_var`，decoder 为 `2 → 256 SiLU → 256 SiLU → 12`，只接收 z。预训练重参数采样，损失为 raw hand MSE 加 beta×KL，KL 对 batch/latent 取 mean。

LAMP 构造函数不接收迭代采样步数。统一推理接口的 `inference_steps` 只接受 `None` 或 `1`，评测使用 `eval.inference_steps=1`。

BC 冻结 prior，将 `[mu,log_var]` 经可训练 `4→128 ReLU→128 ReLU` 与观测条件拼接，ReLU head 输出 7D arm 和 2D latent offset：

```text
arm_pred, delta_z = head(condition)
hand_pred = D(mu + delta_z)
loss = mean((arm_pred-arm_target)^2)
     + hand_loss_weight * mean((hand_pred-hand_target)^2)
     + drift_reg_weight * mean((hand_pred-stopgrad(D(mu)))^2)
```

两个权重默认为 1。arm、hand、history、重建和 drift 均为物理 radians，action normalization 为 identity；无额外 hand affine、sigma 倍乘或 latent-L2 分支。decoder/损失保持 FP32，预测分支向 offset 反传，参考分支 no_grad；不增加 tanh、限位损失或训练硬裁剪。`loss_decoded_hand` 是 raw hand MSE，`offset_rms` 仅诊断 latent offset。

仅当 `drift_reg_weight=0` 且 `log_metrics=False` 时跳过参考 `D(mu)`；开启日志时仍计算全部 drift/prior 指标。默认非零 drift 配方仍执行参考分支。

prior/BC 历史噪声分别为 0.01/0.10 radians；BC 按 Policy.training 控制。joint_state 经训练源行 Gaussian 标准化后，仅前 7 维 arm 加 std=0.10 噪声，measured hand 不加噪，Dataset 不重复叠加。扰动只改输入副本，验证/推理关闭，std=0 不消费 RNG。

prior 训练 shuffle 后丢尾批，验证保留尾批。

## 官方实现与本地适配

| 方法 | 重要的本地差异 |
| --- | --- |
| DQ | 保留 Sparse3D 和现有 runner；本地 `num_layers=6` 计全部隐藏层。导出使用 learned weights（非官方固定 0.5/0.5），按部署 lookup 误差选点 |
| LAMP | 历史只含过去命令，而非官方含 t 的历史；使用 log_var、ReLU head、decoded drift（不等同论文 sigma 特征/latent-L2）；不移植官方真机或 temporal ensemble |

## DQ/LAMP 训练默认值

训练预算、LR、betas、decay、裁剪与调度以 [策略配置](../dexmani_policy/configs/) 和预训练入口为准，避免重复维护数值。需注意：DQ 的 100000 updates 为本地预算；DQ/LAMP Policy 默认 raw，DQ codebook EMA 独立保存；LAMP prior 在 KL warmup 达标后才可选点，BC head/backbone 分开裁剪。优化器按有效 update 推进，关闭裁剪仍检查非有限值；两种 Policy 的观测 encoder 均从头训练。

## LatentFlow 与 HandVAE

本地实现适配 [论文 Step 1/2 与 Appendix A/B.1/B.2](https://arxiv.org/html/2609.19666v1)，保留单臂 7+12 DoF、Sparse3D、现有增强和从头训练的 DiTX；不包含 π₀.₅、DAgger 或在线 RL，不能外推为预训练 VLA 的收敛表现。

### 数据和坐标契约

默认 `H=32,Nobs=2,C=25`，query 为 t：`obs=[t-1,t]`、`q0=state[t]`、`action=command[t:t+H]`。Dataset 返回绝对 `[H,19]` command，reference_state 在观测增强前复制；推理省略 context 时取最新原始 joint_state，整段 chunk 共用一个 q0。

仅采样 H 帧真实未来动作完整的窗口；历史不足补首帧，未来不补帧、不跨 episode。完整生成并双向解码 H 后执行 `[0:C]`，`1<=C<=H`；不建逐源帧 latent cache。

LatentFlowDataset 在 fresh action 统计生成器内按 episode、有限窗口批次读取 command 和 query state，不保留整库数组。相同未来 command 相对不同 query state 的差值仍分别计入训练窗口；恢复直接加载 checkpoint normalizer，不重新 fit。数据装配保留 shape/dt/语义约束，不再完整扫描所选字段；可先用 `datasets.tools.check_data` 离线扫描。统计 affine 或训练 loss/gradient 非有限时明确失败，不过滤窗口。

| 分量 | 训练与解码 |
| --- | --- |
| arm | `command_arm-q0_arm` 使用训练窗口拟合的 relative affine；逆 affine 后加一次 q0 |
| hand | 仅用 codec 的 `r=(command_hand-q0_hand-mean)/std`；解码为 `r*std+mean+q0`，不经过 action affine |

最终输出始终是绝对 19D command。`data_semantics` 声明关节顺序、radians、绝对 command、obs-before-action 和 query reference，冲突时报错；缺少 Zarr 声明时标记 `config_declaration`，不视为独立的采集时序证明。dt 来自数据，不假定频率或重采样；时长解释见 [执行时长对照](仿真评测机制.md#latentflow-执行时长对照)。

### 独立 HandVAE 预训练

HandVAE 只读取 hand command、query hand state、episode 与语义/时间信息，不消费视觉或成功标签。可以使用同构的独立语料；同源时 codec 与 Policy **必须共享 holdout**，使用稳定 source_id 和实际 episode 集合（有 episode_ids 时按 ID 对齐），路径/数量不同不能证明独立。

默认 codec split/model seed=0、90/10、不截断训练 episode；主策略 split seed=42、最多100个训练 episode，模型 seed 独立。同源训练不能直接混用两套默认划分：以下示例显式共用 seed=42 的 manifest，codec 模型 seed 仍为0；独立语料可保留自己的划分。

```bash
LF_SPLIT=robot_data/pick_apple_messy_split.json
python -m dexmani_policy.datasets.tools.make_split \
  --zarr-path robot_data/pick_apple_messy.zarr --output "$LF_SPLIT" \
  --seed 42 --val-ratio 0.1 --max-train-episodes 100
python -m dexmani_policy.training.pretrain.hand_prior.hand_vae --config pretrain/hand_prior/hand_vae \
  zarr_path=robot_data/pick_apple_messy.zarr \
  dataset.split_manifest="$LF_SPLIT" \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
```

修改语料时更换 `zarr_path`，将产出的 `codec.path` 传给 Policy，不沿用 DQ/LAMP 的 DATA 数组。修改 latent_dim 必须重训 codec 和 Policy，不能替换旧 Checkpoint。

模型使用 q0 token、固定 H 时间位置和逐时刻 Gaussian posterior（默认 latent_dim=9、width=128、3 层、4 heads）；训练采样，评估/策略标签使用 posterior mean。统计只来自训练窗口，每窗口使用自身 q0（重叠源帧可重复计入），std 下限 `1e-6`。均值和方差按 episode 分块，以 FP64 前缀和累计动作、平方和及 q0 交叉项，不展开 `[batch,H,12]` 相对动作；块内减去共同原点以减小相消误差，保留原统计总体。位置/一阶/二阶差分 weighted Huber 系数为 1/0.2/0.05，thumb/index/middle 权重 1、ring/pinky 0.5；KL 按 batch/time/latent mean。

训练默认 30k updates、batch=4096；KL 前 4000 updates 为零，随后 4000 线性到 3e-4。**必须有有效 holdout**；每 1000 updates 及最终步骤，按 posterior-mean physical MAE 选最低（平局取更早），不设 KL 门槛或早停，输出文件默认拒绝覆盖。

`codec.pt` 保存模型/统计/来源、选中 `step/beta` 与 `completed_updates`。例如 `step=1000,beta=0,completed_updates=30000` 表示选择了第 1000 步的权重，但整个训练跑满 30k；beta=0 不是加载错误。质量核对需重建保存验证集，用 `training.pretrain.hand_prior.hand_vae.evaluate` 检查 physical MAE（radians）和 KL；单看较低 MAE 或非零 KL 不能证明 latent 有效。

### 双空间 flow 和策略训练

监督 target 为 `[normalized_relative_arm,mu]`；codec encoder 冻结、以 FP32/no_grad 调用 `HandVAE.encode_mean()` 在线产生 posterior mean μ，跳过 log variance 投影，不采样或白化。预训练及报告 KL 的评估继续使用返回 μ/log variance 的 `encode()`；LAMP 与 HandVAE 共用 `hand_prior.losses.diagonal_gaussian_kl()`，对全部 batch/latent 轴取 mean（HandVAE 包含 time 轴）。Flow 定义 `s~0.999*Beta(1,1.5)`、`x_s=(1-s)*noise+s*target`、目标速度 `target-noise`、clean estimate `x_s+(1-s)*v_hat`，方向与原论文相反但自洽。

`L=L_arm_FM+0.25*L_latent_FM+0.75*L_decoded`，各项按自身 batch/time/coordinate mean。decoded MSE 比较示范的 standardized relative hand；decoder 冻结但保留向预测 latent 的梯度，`Policy.train` 后 codec 仍为 eval。`decoded_loss_weight=0` 跳过 decoder 和诊断；`one_step_denoising_hand_mae/rmse` 含示范信息，不能等同完整生成质量（`sampled_hand_*`）；推理 10 步 Euler。

策略默认 30k updates、有效 batch=64、BF16 autocast + FP32 主参数（codec 始终 FP32），优化器/EMA/调度值以配置为准。物理逆变换统一由 `HandVAE.denormalize_actions` 完成。

```bash
# 单卡训练，先准备 codec
bash scripts/training/train.sh latent_flow \
  dataset.split_manifest="$LF_SPLIT" \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 梯度累积保持 nominal batch=64
bash scripts/training/train.sh latent_flow \
  dataset.split_manifest="$LF_SPLIT" \
  dataloader.batch_size=16 training.loop.gradient_accumulation_steps=4 \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 恢复完整策略无需原 codec 文件
bash scripts/training/train.sh latent_flow '+resume_from=experiments/latent_flow/<task>/<run>'
```

`max_updates` 只限制本次更新数，不改变总预算；有效 batch = microbatch × 梯度累积，epoch 尾组按实际样本数计算。搬迁和恢复约束见 [Epoch 级恢复](项目架构.md#epoch-级恢复)。

## 预训练数据与选点

| 方法 | 有 holdout | 无 holdout | 产物 |
| --- | --- | --- | --- |
| DQ VQ | `val_lookup_mse` | `train_lookup_mse`，标记 train_no_holdout | VQ checkpoint、codebook NPZ |
| LAMP | KL 达目标后的 deterministic prior-mean MSE | 最终合格步骤 | prior checkpoint |
| HandVAE | 首次计划评估起的 posterior-mean physical MAE | 拒绝训练 | codec.pt |

DQ 的 `hand_data` 只保存动作键，布局/单位由局部产物与输入检查保证；LAMP 另保存 dt、窗口与历史语义。所有手部产物的实际身份/划分统一存于 canonical `split_manifest`；HandVAE/LatentFlow 的 `hand_data` 仅保存 contract 和语义声明来源。HandVAE 允许独立语料，同源共享 episodes 按 ID 核对 holdout；DQ/LAMP 直接比较完整 manifest。HandVAE metadata 另存 `zarr_path`，仅在 source_id 缺失时辅助判断同源；source_id 来自 Zarr。诊断计数留在训练日志和指标中，描述 metadata 不构造验证视图。VQ 的 `codebook_diagnostics.json` 记录 NN→lookup 的 normalized/physical 误差、利用率和跳变；选点用 normalized MSE，导出读取显式 selection_split/metric，不从 episode 列表推断。

## 加载

| 方法 | 新训练必须匹配 |
| --- | --- |
| DQ | 手部 affine、相同的实际 split，`pose_space=normalized`，prototype 布局、pca_permutation 与有限值 |
| LAMP | `coordinate_space=raw_joint_targets_radians`、关节顺序、架构和相同的实际 split |
| LatentFlow | codec 结构、H、顺序/单位/q0/时间语义、dt（相对容差 1e-6）及来源/holdout；语料规模可不同 |

独立 VQ/LAMP 产物保存数据定位/划分参数、实际 split、模型和预训练配方。LAMP prior 和 LF codec 直接加载到 Policy 已构造的模块。

完整 Policy 的 raw/EMA 内嵌表示权重和统计，effective_config 保存 metadata；推理无需原表示文件或训练数据；resume 严格核对配置、实际 split 与训练状态，并恢复保存的统计。预训练产物校验字段、权重、统计和 ready 状态；VQ/LAMP/HandVAE 独立预训练均不提供完整续训。DQ/LAMP 默认 raw，请求不存在的 EMA 会失败。

更换 VQ codebook 后须重训下游 Policy，不能替换已训练 Policy 的内嵌码本。数据重新生成使用新路径，历史产物沿用对应源码。

LAMP/LatentFlow 仅 sync，拒绝 prefix/delay；历史由执行端维护，格式见 [部署边界](项目架构.md#部署边界)，真机闭环 **NOT VERIFIED**。
