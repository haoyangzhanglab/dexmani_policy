# 手部动作表示

下列方法都从示教学习绝对关节目标，默认每步 19 维（7 维手臂、12 维手部）。它们的区别在于模型生成什么，以及如何将生成结果还原为关节目标。

| 策略 | 模型生成的表示 | 如何得到关节目标 |
| --- | --- | --- |
| DAI-Flow (`interaction_flow`) | 每个控制时刻的 19 维动作用一个 token 表示 | 生成整段轨迹并反归一化。 [模型架构](InteractionFlow模型架构.md) |
| SAT | 每个关节在整个窗口内的轨迹用一个 token 表示 | 还原轨迹排列和关节尺度 |
| DQ-RISE | 7 维手臂目标和 1 个连续手姿索引 | 离散化索引，查询固定手姿码本 |
| DexLatent | 7 维手臂目标和 32 维手姿潜变量 | 用冻结的解码器还原手部关节目标 |
| ODE | 关节空间向量场，可选速度偏移 | 从上一条有效关节目标开始积分 |

SAT、DQ-RISE 和 DexLatent 共享 RGB、点云和关节状态编码。三者均在表中各自的生成空间训练 Rectified Flow。

## 手部先验

- **DQ-RISE** 从示教的手部目标训练残差 VQ-VAE，将解码出的手姿按 PCA 排序成码本。把已解析的 `dqrise` 配方传给 `bash scripts/pretrain/vqvae.sh --policy-config "$POLICY_CONFIG"` 即可复用数据划分。下游通过 `initialization.codebook=<run>/codebook.npz` 载入码本。 [同源数据预算](观测预训练.md#同源数据预算)
- **DexLatent** 用冻结的 XHand 编码器将手姿表示为潜分布的均值，再用冻结的解码器还原手指关节。 [预训练权重](../data/README.md)

## ODE 的动作对齐

ODE 以点云历史和最新实测关节状态为条件，从上一条实际应用的关节目标积分 `n_action_steps` 个控制周期。训练时取上一拍的 `action`，段首取实测状态。仿真取环境实际应用的目标，在线跳过控制步后从实测状态重新规划。

真机示教的等待拍沿用本段最近一次成功提交的目标，首次提交前取段首实测状态。导出时需要 `joint_state`、`point_cloud`、`action` 三个字段。 [示教数据格式](仿真数据集格式.md)
