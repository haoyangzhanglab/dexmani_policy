# DexMani_Policy 手部动作表示

DQ-RISE、LAMP 和 LatentFlow 是本地研究适配；观测、窗口和训练目标有差异，不应直接视为纯动作空间消融。通用接口见 [项目架构](项目架构.md)，命令从仓库根目录执行。

## 数据与准备

数据契约为 `obs[t]` 在 `action[t]` 提交前采集，动作是 7 维 arm joint targets + 12 维 hand joint targets。手部顺序为 XHand thumb×3、index×3、middle×2、ring×2、pinky×2，单位 radians，要求有限正 `dt`。不自动移位或猜测旧数据语义。

DQ/LAMP 默认 episode 级 9:1 划分、无 episode 数截断。正式预训练和 policy 必须显式复用同一 manifest；生成一次后跨阶段、跨 policy seed 使用，不能分别抽签。缺少真实 ID 的数据可记录实际 episode 索引、路径和边界，不补造 trial 身份；已有确认的 trial manifest 继续校验 trial 不跨 split。格式见 [划分与数据身份](项目架构.md#划分与数据身份)。

```bash
conda activate policy
DATA_ZARR=/path/to/dataset.zarr
SPLIT=/path/to/episode_split.json
# 首次生成；已有清单直接复用，生成入口拒绝覆盖。
python -m dexmani_policy.datasets.common.episode_split \
  --zarr-path "$DATA_ZARR" --output "$SPLIT" --val-ratio 0.1 --seed 42
HAND_RUN="experiments/hand_spaces/$(date +%Y%m%d_%H%M%S)_${RANDOM}"
DATA=("zarr_path=$DATA_ZARR" "dataset.split_manifest=$SPLIT"
      dataset.max_train_episodes=null dataset.val_ratio=0)
```

manifest 已定义最终集合，故加载时 `val_ratio=0` 不代表清空其中的 validation。显式子集通过清单生成入口的 `--max-train-episodes` 或现有 trial 清单定义；无 holdout smoke 使用 `--val-ratio 0`，指标明确标注 train。索引清单绑定原数据路径；更换数据路径需重新生成并核对清单，不能自动重映射。

公共 normalizer 只遍历有效训练窗口实际消费的源行，按字段去重、分块读取，排除 validation、exclusions 和未消费行；LatentFlow relative action 按窗口与 q0 统计。验证复用训练统计且不增强。DQ/LAMP 的表示与 policy 要求数据身份和清单一致；HandVAE 的独立语料约定见下文。

## DQ-RISE 码本

```bash
VQ_DATA=()
for item in "${DATA[@]}"; do VQ_DATA+=(--policy-override "$item"); done
python -m dexmani_policy.training.pretrain.hand_prior.vqvae \
  --policy-config dexmani_policy/configs/dqrise.yaml \
  "${VQ_DATA[@]}" --output_dir "$HAND_RUN/dqrise"
python -m dexmani_policy.training.pretrain.hand_prior.export_codebook \
  --checkpoint "$HAND_RUN/dqrise/vqvae_hand_best.pt" \
  --output "$HAND_RUN/dqrise/codebook.npz"
bash scripts/training/train.sh dqrise "${DATA[@]}" \
  codebook_path="$HAND_RUN/dqrise/codebook.npz"
```

采用 [DQ-RISE v2 §III](https://arxiv.org/html/2509.17450v2)，代码依据固定 commit [2889d27](https://github.com/rise-policy/DQ-RISE/tree/2889d27fce823288e8dd12ec6e91506b52ed086a)。默认 `codebook_path=null`，新训练必须提供当前格式产物。便捷 shell 入口仍转发 VQ 参数，需同时传入上述划分 overrides。VQ 的布尔 CLI 使用 `--kmeans_init` / `--no-kmeans_init`，不接受附加字符串值；YAML 仍使用布尔值。

VQ 只量化单步 normalized hand target。encoder/decoder 每侧 6 个 512D 隐藏 Linear + ReLU，latent 256；两层 residual quantizer、每层 4 code，共 16 个组合。Linear 正交初始化、零 bias；EMA decay 0.8，`kmeans_init=false`、`threshold_ema_dead_code=0`，`act_scale=1`。残差减去 detached quantized，训练使用 straight-through，commitment 对 code 停梯度；各层输出按 learned softmax weights 合成。

目标为 `3 * mean(abs(reconstruction-target) * joint_weight) + 5 * sum(commitment)`，前 8 个关节权重 1、后 4 个权重 0.5，对应上述真实手指顺序。reconstruction MSE 仅辅助记录。

训练评估和导出共用：组合枚举 → learned weights 合成 latent → decoder → act_scale → clamp 到 `[-1,1]`。导出在解码后的手姿空间做 PCA 排序。标签来自最终部署表的最近 normalized prototype；`s=2*i/(M-1)-1`，解码为 `floor((clamp(s,-1,1)+1)*(M-1)/2+0.5)`，再查表并逆 action affine 得到物理命令。

每个 epoch 后，以固定模型 eval/no_grad 计算 `lookup_mse = sum_i min_j ||hand_norm_i-prototype_j||² / (N*12)`。有 holdout 使用 `val_lookup_mse`；否则独立遍历完整训练源行，包括尾批，使用 `train_lookup_mse` 并标记 `train_no_holdout`，不写入伪 validation 指标。日志中的 lr 是该 epoch 最后一次 optimizer update 实际使用的值。评估不更新 EMA codebook。PCA 排序不改变最近邻误差。

### 窗口与 diffusion

DQ 使用 `Nobs=1,H=20,C=16`：UNet 生成 `[B,20,8]`，内容为 7 arm + 1 hand index，查表后输出 `[B,20,19]`。执行 `[0:16]`，首项就是最新 `obs[t]` 后的 `action[t]`。sampler 保持 `pad_before=0,pad_after=15`，末端动作重复 padding；可用 query 数遵循已有 sampler 规则，不额外整体移位。

UNet timestep embedding 256、down_dims `[256,512]`、kernel 5、GroupNorm 8；FiLM 使用 `scale*x+bias`。DDIM 为 100 training timesteps、20 denoising steps、epsilon prediction、squared-cosine。官方评测脚本中的 `num_inference_step=16` 是重新查询间隔，不是 DDIM 步数。

SAT 保持原来的 `Nobs=2,H=16,C=8` 和动作网络。两者共享 Sparse3D global 编码方式，但时间输入和融合层输入宽度不同，DQ 的 condition 输出仍为本地 256D，不增加投影网络。

## LAMP 历史先验

```bash
python -m dexmani_policy.training.pretrain.hand_prior.lamp --config lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
bash scripts/training/train.sh lamp "${DATA[@]}" \
  lamp.prior_path="$HAND_RUN/lamp/prior.pt"
```

依据 [LAMP v1](https://arxiv.org/html/2607.06323v1) 与固定 commit [0467ba3](https://github.com/dex-lamp/LAMP/tree/0467ba3504e0d199727a0586ba525c5fe14f8138)，仅实现 prior 预训练和 BC，不包含 RL。产物默认写入 `agent.prior_path`；使用 `--output` 时需同步 policy 路径。

历史为 `action[t-8:t]`，target 为 `action[t]`，保持 H=Nobs=C=1。episode 开始时用初始实测手姿补齐，不用未来监督命令；在线队列只记录实际下发的物理手部命令，每个 episode 清空。

prior encoder 为 `flatten(8×12) → 256 SiLU → 256 SiLU → 独立 mu/log_var`；decoder 为 `2 → 256 SiLU → 256 SiLU → 12`，只接收 z。预训练使用 `z=mu+exp(0.5*log_var)*epsilon`，目标为 raw hand MSE mean 加 beta×KL，KL 对 batch 和 latent 维同时取 mean。

LAMP prior 正常训练每轮 shuffle 后丢弃尾批；训练源行数不足一个 batch 的小数据 smoke 每轮保留单个不足 batch，并记录实际 batch size；验证集仍保留全部样本和尾批。

BC 的冻结 prior 产生 `[mu,log_var]`，通过可训练 `4→128 ReLU→128 ReLU`，与原观测编码器输出拼接；`[512,512,256]` ReLU head 输出 7 arm + 2 latent offset：

```text
arm_pred, delta_z = head(condition)
hand_pred = D(mu + delta_z)
loss = mean((arm_pred-arm_target)^2)
     + hand_loss_weight * mean((hand_pred-hand_target)^2)
     + drift_reg_weight * mean((hand_pred-stopgrad(D(mu)))^2)
```

两个权重默认均为 1。arm、hand、history、prior reconstruction 和 drift 全部使用本地物理 radians，`normalization.action=identity`；没有 hand affine、sigma 倍乘、latent 标签或 latent-L2 训练分支。prior 参数冻结，`D(mu+delta_z)` 保留对 offset 的梯度；参考分支 no_grad。先验统计、decoder 和损失维持 FP32。训练不新增 tanh、关节限位损失或硬裁剪；执行侧合法限位处理保持原样。

BC 日志用 `loss_decoded_hand` 记录 raw hand MSE，`offset_rms` 仅用于诊断 latent offset，不重复输出同义 hand MSE 或 latent-L2 字段。raw prior 的元数据不保存 action affine 或观测归一化约束。

prior/BC history noise 分别为 0.01/0.10 radians，独立作用于各 batch、历史位置和关节。BC 由 policy.training 控制，不能用 frozen prior.training 判断。joint_state 按有效训练窗口消费的源行做 Gaussian 标准化，然后仅对前 7 维 arm 加 std 0.10 噪声，12 维 measured hand state 不额外加噪；dataset 不再叠加 state noise。所有扰动只作用输入副本，验证/推理关闭，std=0 不消费额外 RNG。不同机器人使用同样的原始坐标运算，不意味着物理扰动效果相同。

## 官方实现与本地适配

| 项目 | 官方有效路径 → 本地实现 → 必要适配 |
| --- | --- |
| 观测与动作 | 保留本地 Sparse3D、点云处理、proprio 与融合；不引入 MinkowskiEngine/ResNet。动作采用本地 7+12 joint targets、radians |
| DQ 深度 | shell `vae_layer_num=5` 另有输入隐藏层 → 本地 `num_layers=6` 表示隐藏层总数 |
| DQ 导出/选点 | 官方训练 learned weights、导出固定 0.5/0.5 → 本地统一 learned weights；保留最近整数解码及部署 lookup 选点正确性改进 |
| LAMP 条件与正则 | 论文 Eq.5 使用 sigma、Eq.6 使用 latent-offset L2 → 采用代码 log_var 特征、ReLU head 和 decoded drift；不声称两种正则等价 |
| LAMP BC 配方 | 论文表格 lr=5e-4/warmup=500 → 采用 train_example_jax.sh 与 CLI 合成的 lr=1e-4/warmup=1000 |
| LAMP 时序 | 官方数据 history 到 t、target t+1 → 按本地 obs-before-command 契约使用严格过去命令，不复制数组位移或动作 bootstrap |
| LAMP 选点 | KL warmup 后按 deterministic prior-mean validation MSE → 保留本地部署导向改进，不称官方原有策略 |
| 执行 | 保留本地同步/runner/限位接口，不移植官方真机或 temporal ensemble |

## DQ/LAMP 训练默认值

| 阶段 | batch / 预算 | AdamW lr / betas / decay | 调度、裁剪 |
| --- | --- | --- | --- |
| DQ VQ | 256 / 1500 epochs | 3e-4 / (0.95,0.999) / 1e-6 | cosine，warmup 150，关闭裁剪 |
| DQ policy | 128 / 100000 updates | 3e-4 / (0.9,0.999) / 1e-6 | cosine，warmup 2000，关闭裁剪 |
| LAMP prior | 256 / 20000 updates | 2e-3 / (0.9,0.999) / 1e-4 | min_lr=1e-5，warmup 500，clip 1；beta=1e-3，KL warmup 2000 |
| LAMP BC | 128 / 20000 updates | 1e-4 / (0.9,0.999) / 1e-4 | min_lr=1e-6，warmup 1000，head/backbone 分别 clip 1 |

DQ policy 的 100000 updates 是保留的本地预算；官方示例的 5 epochs 不是正式预算依据。DDP overlay 仍为 32×4 的有效 batch 128。DQ/LAMP 参数全部按对应 AdamW 组应用 decay，包括 bias；LAMP head 裁剪组包含动作头、prior-feature MLP 和现有 proprio MLP，backbone 组包含 Sparse3D。学习率组可独立设置 obs_lr，裁剪仍按上述两组聚合。观测编码器从头训练，默认 obs_lr 分别为 3e-4/1e-4，不采用预训练视觉网络的冻结或 0.1 倍率。

两种 policy 默认训练/评测均关闭额外 model EMA，使用 raw model；DQ codebook EMA 保留。关闭裁剪不关闭非有限值检查。LAMP LR warmup 按官方 linspace，update 0 为零、W−1 到 peak，W 为 cosine 首项；最后一次实际更新略高于理论 min_lr。KL 同样从 update 0 的零值开始，达到目标后才允许选点。DQ 复用 diffusers cosine/warmup。所有调度均按 optimizer update 推进。

## LatentFlow 与 HandVAE

`LatentFlow` 是项目名称，适配 [论文 Step 1/2、Appendix A/B.1/B.2](https://arxiv.org/html/2609.19666v1) 的手部表示与监督训练；保留单臂 7＋12 DoF、Sparse3D 观测编码、原观测增强和从头训练的 DiTX，不实现 π₀.₅、DAgger 或在线 RL。附录优化配方用于对照，不能据此推断预训练 VLA 的收敛表现。

### 数据和坐标契约

默认 `H=32、Nobs=2、C=25`。query 为 t：`obs=[t-1,t]`，`q0=state[t]`，`action=command[t:t+H]`。Dataset 返回原始绝对 `[H,19]` command；`action_context.reference_state [19]` 在观测增强前复制。推理没有显式 context 时取原始最新实测 joint_state，整段 chunk 使用同一个 q0。

仅采样有 H 帧真实未来动作的起点，历史不足重复 episode 首帧，未来不补帧、不跨 episode。这是本地边界约定。采样、有效性过滤、source-row 统计及执行共用同一时间轴；历史 action 不作为未来标签过滤。完整生成和双向解码 H 帧后执行 `[0:C]`，支持 `1<=C<=H`。不建逐源帧 latent cache。

arm 使用训练窗口拟合的 relative-command affine：先 `command_arm-q0_arm`，再取 19 维 action normalizer 的前 7 维参数；推理逆 affine 后加一次 q0。hand 仅使用 codec 的 `r=(command_hand-q0_hand-mean)/std`，decoder 输出 r，物理解码一次 `r*std+mean+q0`。最终始终为绝对 19 维 command，手部不经过 action affine。

`data_semantics` 显式声明项目原有 arm 顺序与 XHand thumb×3/index×3/middle×2/ring×2/pinky×2 的块内采集顺序、radians、绝对 command 和 `obs[t]_before_action[t]`。Zarr 声明冲突则拒绝；缺少属性时 metadata 标明 `config_declaration`，不能视为对历史采集时序的独立证明。现有采集实现与该对齐一致，不平移标签。`dt` 来自数据，不假定 30 Hz、不重采样；当前 pick_apple_messy 的 dt≈0.0625s，H/C 为约 2s/1.5625s 的控制周期，首末样本跨度分别是 `(H-1)dt` / `(C-1)dt`。

### 独立 HandVAE 预训练

`hand_vae.yaml` 仅消费现有 Zarr 的 hand command、query hand state、episode 与语义/时间信息，不加载视觉、不构建观测编码器、不按成功标签筛除失败轨迹。数据可以与策略语料不同。默认 episode 90/10、唯一 seed 0、不限制训练 episode 数；同源策略默认 split seed 0、10% holdout、最多 80 个训练 episode，模型初始化 seed 42 独立。当前 125-episode 示例为 codec train 113、policy train 80、共同 holdout 12；资格过滤后的窗口数分别记录。

来源用 `dataset.source_id`（优先核对 Zarr 同名属性，否则默认规范路径）和实际 episode 集合记录；复制数据应保留同一个 source_id，有稳定 episode_ids 时按 ID 对齐。同源共享 holdout，允许训练子集、视觉资格和窗口数不同；不同源不要求 episode 数一致。没有身份信息的复制件不能靠路径或数量证明独立，不能绕过来源声明。显式 manifest 仍定义最终集合，加载时设 `val_ratio=0、max_train_episodes=null`；同源可用同一 seed 生成无预算 codec 清单和 80-episode policy 清单，验证集合须一致。

模型每侧 width 128、3 层、4 heads、MLP ratio 2，q0 token、固定 H 的时间位置参数、逐时刻 Gaussian posterior；默认 latent_dim=9 且可配置。保留 pre-norm、GELU、dropout=0、现有末端 LayerNorm 等未由作者实现进一步确认的选择，不按参数量差额增添层。预训练重参数采样，评估及策略标签使用 posterior mean。

统计只来自训练窗口，每个窗口保留自己的 q0；重叠帧重复计入，std 使用 population moments 和 `1e-6` 下限。位置/一阶/二阶差分 weighted Huber 为阈值 1、系数 1/0.2/0.05；thumb/index/middle 权重 1，ring/pinky 权重 0.5，只乘分子，分母为 batch×有效帧数×关节数。差分匹配示范运动，不是趋零平滑。KL 明确为 batch/time/latent mean，不额外乘 H 或 latent_dim。

默认 30k optimizer updates、完整 batch 4096、AdamW LR 3e-4、weight decay 1e-4、cosine。前 4000 updates 的 KL 为零，接下来 4000 线性到 3e-4。必须有有效 holdout，每 1000 updates 及最终步骤按 posterior mean 的整体物理 MAE 选最低值，平局保留较早模型，并记录逐关节 MAE（radians）。所有评估点均可选，不设 8k 门槛；完成全部预算，不早停。产物 `codec.pt` 保存选择 step/beta、完成 updates、统计、结构与来源。已有输出默认拒绝覆盖。

```bash
python -m dexmani_policy.training.pretrain.hand_prior.hand_vae --config hand_vae \
  zarr_path=robot_data/pick_apple_messy.zarr \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
```

更换独立语料只修改该预训练命令的 `zarr_path`，随后将 codec 路径传给策略；不继承上文 DQ/LAMP 的 DATA 数组或 80-episode 预算。配置 seed 是唯一预训练 seed，数据划分、shuffle 和模型随机性均使用它。

### 双空间 flow 和策略训练

target 为 `[normalized_relative_arm, mu]`，冻结 encoder 在 FP32/no_grad 下在线产生 μ，不采样、不白化。保留 `s~0.999*Beta(1,1.5)`、`x_s=(1-s)*noise+s*target`、速度 `target-noise` 和 clean estimate `x_s+(1-s)*v_hat`，与论文时间反向但自洽。

`L=L_arm_FM+0.25*L_latent_FM+0.75*L_decoded`，每组按自身 batch/time/coordinate mean。decoded MSE 对比真实示范的 standardized relative hand，而非 codec 重建标签；冻结 decoder 保留对预测 latent 的梯度，`policy.train()` 后 codec 仍 eval。`decoded_loss_weight=0` 完全跳过 decoder 及相关指标。训练日志 `one_step_denoising_hand_mae/rmse` 是带示范信息的一步诊断，不是纯噪声生成精度；完整采样指标使用 `sampled_hand_*`，仅在显式完整采样评估时计算。推理保留 10 步 Euler。

策略默认 30k updates、global batch 64，AdamW betas=(0.9,0.95)、eps=1e-8、weight decay=1e-10；沿用项目参数分组，bias/norm 等 no-decay。主干与观测 encoder peak LR 均 5e-5，warmup 1000，复用 `cosine_min_lr`、ratio 0.1，global clip 1，固定 EMA decay 0.99。从第一次 optimizer update 起按 0.99 更新，默认未配置 fixed_decay 的其他策略仍用原 EMA 日程。沿用离散 scheduler，最后一次实际 LR 略高于理论 5e-6 下限。

FP32 主参数、BF16 autocast、codec FP32 是本地精度适配，不称全 BF16 参数。codec 的设备、输入 FP32 和 autocast 边界由预训练/策略调用者管理，内部不重复转换张量；物理逆变换共用 `HandVAE.denormalize_actions`。关节损失权重只在 `hand_vae.yaml` 配置并随 codec 保存，策略配置不再重复声明未消费的权重。batch 配置仍为每卡数；日志分别记录 nominal global batch、累积尾组实际 batch 和处理窗口预算。默认 accumulation=1；改为累积时保留现有尾组行为，不声称每个尾组都是 64。

```bash
# 单卡 64×1×1
bash scripts/training/train.sh latent_flow \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 四卡 16×4×1
bash scripts/training/train_ddp.sh latent_flow '+training.num_gpus=4' \
  dataloader.batch_size=16 training.loop.gradient_accumulation_steps=1 \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 只限制本次短跑，不改总预算
bash scripts/training/train.sh latent_flow '+max_updates=4' workspace.wandb_cfg=null \
  codec.path=experiments/hand_vae/pick_apple_messy/codec.pt
# 恢复完整策略不要求原 codec 文件继续存在
bash scripts/training/train.sh latent_flow '+resume_from=experiments/latent_flow/<task>/<run>'
```

Fresh training 校验 codec 结构、H、坐标/单位/顺序/q0/时间语义和 dt（仅允许相对 1e-6 的浮点表示误差），不要求语料规模一致。完整策略的 raw/EMA state_dict 包含 codec 权重和统计，effective_config 包含 codec metadata 和独立 policy hand_data；load/resume 不依赖外部 codec。resume 仍严格核对完整训练配方、实际数据划分与有效窗口、optimizer、scheduler、EMA、RNG 和游标。独立 codec 产物用于初始化，不另建预训练恢复子系统。

## 预训练数据与选点

| 方法 | 有 holdout | 无 holdout | 当前产物 |
| --- | --- | --- | --- |
| DQ-RISE VQ | 按 `val_lookup_mse` | 按 `train_lookup_mse`，标记 `train_no_holdout`，可导出 | VQ checkpoint、codebook NPZ (`pose_space=normalized`) |
| LAMP | deterministic prior-mean MSE | 最终合格步骤 | prior checkpoint |
| HandVAE | posterior-mean physical MAE | 拒绝训练 | codec.pt |

LAMP 的 KL 合格步骤规则保持原行为。HandVAE 从首次计划评估参与选点且必须有 holdout，具体预算与指标见上文。

`hand_data` 保存 episode 身份/边界、train/val 集合、动作键、dt、窗口/历史长度及样本计数。它不计算内容哈希，数据重新生成使用新路径。VQ 的 `codebook_diagnostics.json` 记录实际 NN→lookup 的 normalized/physical 误差、利用率与跳变；各 split 的 `lookup_mse` 是 normalized MSE，与选点指标对应。VQ checkpoint 显式保存 `selection_split`、`selection_metric` 和对应 metrics，导出直接读取，不从 episode 列表推断选点 split。

## 加载

Fresh training 核对坐标：DQ 核对手部 affine 和 manifest，LAMP 核对 raw-radians 坐标、架构和 manifest，LatentFlow 使用内嵌 codec 相对统计并按上文规则校验独立来源；观测归一化可在 encoder 约束内另选，Sparse3D 点云仍须 `identity`。

policy strict resume 用 checkpoint 内嵌表示并重新核对保存的 `hand_data`；独立推理无需原表示文件或训练数据。DQ/LAMP 默认 raw-model；请求不存在的 EMA 必须报错。VQ/LAMP prior 产物保存表示权重、结构、数据配方和选点指标，不保存无消费入口的 optimizer/scheduler 状态；预训练不提供完整续训。policy checkpoint 仍完整保存 optimizer、scheduler、RNG 和游标用于 resume。

DQ VQ/codebook 格式分别为 `dexmani.dq.vqvae.v2` / `dexmani.dq.codebook.v2`，LAMP prior 为 `dexmani.lamp.raw_prior.v1` 且 `coordinate_space=raw_joint_targets_radians`。DQ codebook 使用 `pose_space=normalized`，核对原型布局、`pca_permutation`、有限值和 normalizer 一致性。配置、预训练 checkpoint 和 NPZ 只按当前字段及张量结构读取，不迁移或补齐旧产物；格式不匹配的产物须用对应预训练入口重新生成，历史实验使用对应源码。LatentFlow 的未来窗口和 relative 坐标规则不应用到 DQ/LAMP；已有产物不覆盖、不迁移。

新的 VQ 选点不会修改已训练 Policy 内嵌的码本。选择不同码本后，下游 Policy 需要重新训练，不能直接替换旧 Policy 的码本。

LAMP/LatentFlow 仅支持 sync，拒绝 prefix/delay。LAMP 的 `action_context.hand_history` 由执行端维护，`predict` 不更新历史；格式与执行职责见 [部署边界](项目架构.md#部署边界)，真机闭环 **NOT VERIFIED**。

预训练与导出入口位于 `training/pretrain/hand_prior/`，表示模型位于 `agents/hand_prior/`，历史/q0 Dataset 位于 `datasets/hand_prior/`，均相对于 `dexmani_policy/`。
