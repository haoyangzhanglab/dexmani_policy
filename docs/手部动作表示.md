# 手部动作表示

SAT、DQ-RISE、DexLatent 与 ODE 都输出手臂与手部的绝对关节目标。

## 表示与生成方式

| 方法 | 模型生成什么 | 如何还原动作 |
| --- | --- | --- |
| SAT | 19 个关节的整段轨迹 | 还原轨迹排列与关节尺度 |
| DQ-RISE | 7 个手臂关节与 1 个连续手姿索引 | 将索引离散化，在固定码本中选择手姿 |
| DexLatent | 7 个手臂关节与 32 维连续手部潜表示 | 使用冻结解码器还原手部关节目标 |
| ODE | 关节空间向量场与可选速度偏移 | 从上一条实际下发目标积分为关节轨迹 |

SAT、DQ-RISE 和 DexLatent 共享空间观测编码与 Rectified Flow，均在整个生成空间上计算 MSE。`time_shift_alpha` 调节均匀采样的训练时间，推理使用等间隔 Euler 积分。

## SAT：按关节组织轨迹

SAT 将同一关节在动作窗口内的轨迹作为一个 token，联合建模各关节。Flow 学习生成过程中的变化方向，最终动作是绝对关节目标。

## DQ-RISE：从固定码本选择手姿

DQ-RISE 从原始示教帧的手部关节目标训练残差 VQ-VAE，解码所有码本组合得到整只手的姿态原型，并在归一化手部空间用 PCA 排序。有验证集时以查表误差选模，否则采用最终模型。

用 `bash scripts/pretrain/vqvae.sh --policy-config "$POLICY_CONFIG"` 复用下游预算。策略继承码本的手部尺度，从本次训练数据拟合手臂尺度。推理时将连续索引离散化后查表。 [同源数据预算](观测预训练.md#同源数据预算)

## DexLatent：在连续先验空间生成手姿

DexLatent 冻结预训练的 XHand 编码器和解码器，以编码分布的均值作为确定性的手姿表示。策略继承先验的动作尺度，从本次训练数据拟合潜表示尺度。推理时解码生成的潜表示，得到手部关节目标。

比较两种手部先验时应报告数据来源。DQ-RISE 的码本从本地示教学习，DexLatent 使用外部权重。 [预训练资源](../data/README.md)

## ODE：从上一条指令积分生成轨迹

ODE 以点云历史和最新实测关节状态为条件，从上一条有效关节目标积分 `n_action_steps` 个控制周期。仿真使用环境实际应用的目标。

Real 的 `action_ode` 按原时序保留主机最近接受的完整命令目标。命令失败或未发送时沿用上一目标。新段以实测关节状态起步，在线调度跳过控制步后也从实测状态重新规划。在 `dexmani_real` 中用 `scripts/export_zarr.py` 的 `--fields joint_state point_cloud action_ode` 导出，原始记录须包含逐行命令提交状态。
