# 触觉与交互建模

触觉描述正在发生的接触。未来力预测既可以参与动作生成，也可以只用于训练交互表征；AdapTac 与 InterAct-Dex 分别采用这两种方式。

## 触觉表征

| 表征 | 编码内容 |
| --- | --- |
| force | 每根手指的汇总力 |
| taxel | 密集触觉单元的通道信息 |
| patch | 从密集触觉中提取区域描述，再汇聚为手指特征 |

这些表征对应不同的输入组织方式。当前仿真提供五指汇总接触力，不提供密集触觉；真实传感器通道的尺度和坐标也不能直接视为与仿真一致。

## AdapTac：未来力引导动作生成

AdapTac 先编码场景点云与触觉，再通过双向注意力融合视觉和接触信息。未来力扩散模型根据观测历史预测未来绝对力，预测结果进一步引导特征融合，作为动作扩散的条件。

其主要链路为：**视觉与触觉交互 → 未来力预测 → 力引导融合 → 动作生成**。

未来力分支同时参与训练和在线推理。训练时使用未来力监督，推理时从噪声采样未来力，再生成动作。

## InterAct-Dex：建模身体与交互历史

InterAct-Dex 围绕腕部与五指组织身体特征，结合实测末端位姿、指尖位置和关节状态读取局部几何，再利用触觉调制手指表征。

历史编码连接同一帧的身体部位，并沿时间建模各部位的交互变化。身体历史与独立场景特征共同作为动作 Flow 的条件。

训练时可加入未来力分支，预测相对当前力的变化量，为交互学习提供辅助监督。该分支不参与在线动作生成，当前触觉仍作为观测参与推理。

## 两种方法的区别

| 方法 | 未来预测目标 | 在策略中的作用 |
| --- | --- | --- |
| AdapTac | 未来绝对力 | 直接引导在线动作生成 |
| InterAct-Dex | 相对当前力的增量 | 仅提供训练辅助监督 |

两种方法最终都输出物理关节目标。共享模块见[项目架构](项目架构.md)，观测来源见[仿真数据集格式](仿真数据集格式.md)。
