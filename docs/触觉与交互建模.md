# 触觉与交互建模

## AdapTac

AdapTac 用场景点云与触觉预测未来绝对接触力，再用力预测引导视觉与触觉融合，结合关节状态生成动作。

`bash scripts/training/train.sh adaptac` 默认使用五指汇总力 `finger_tactile_force`，与 `dexmani_sim` 的评测观测一致。数据含密集触觉 `taxel_tactile_force` 时，训练可用 `tactile=taxel` 选择对应编码器。两种配置均沿用数据源的触觉坐标、单位和尺度。 [示教数据格式](仿真数据集格式.md)

训练时将无效标签置零，再对真实未来力加噪，用一步去噪结果引导动作。显式力损失按每次更新的有效元素取均值。设 `agent.force_loss_weight=0` 后，力预测器仍参与动作生成并接收动作损失的梯度。部署时从噪声采样未来力，条件来自当前观测。 [AdapTac 官方实现](https://github.com/kingchou007/adaptac-dex/blob/60e2ef1b7b0a29f5d29f5d755e8fe6d048f69fa5/src/adaptac/policy/FFG_policy.py)

## 多模态交互编码器

`MultimodalInteractionEncoder` 是独立组件，提供场景与手部的空间 token 及几何锚点。

- 场景分支按相机标定将点云 patch 与 RGB 对齐，在 patch 中心或有效邻域采样图像特征。
- 手部分支从腕部位姿和指尖位置生成 token，以三维相对位置为偏置读取场景。随后以五指汇总力做门控残差融合，零力时残差为零。手部 token 按腕部、拇指、食指、中指、无名指、小指排列。

场景点云、末端位姿与指尖共用米制基座坐标，外参将该坐标变换到 OpenCV 相机坐标系。末端 6D 旋转依次取旋转矩阵前两列，指尖相对腕部表示。腕部、局部指尖和手部到场景的相对位置各自缩放，输出锚点保留米制坐标。 [数据集坐标](仿真数据集格式.md#几何坐标)

残差与全局汇总、手指身份编码和逐特征门控分别参考以下实现。 [DeCAL](https://github.com/AureleoPKU/DeCAL/blob/09de1855cfc933a2d2680d6011744476647ed7d1/src/lerobot/policies/DeCAL/modeling_decal.py) · [DexTacWAM](https://github.com/dextacwam/DexTacWAM/blob/4f7c5a80dda2ca06667a9a583075d8c92108eb56/models/tactile_models/visual_vae_adapter.py) · [DECO](https://github.com/BAAI-Humanoid/DECO/blob/fdd159e2a149ff0b91f001569ae7e9d60220697c/models/deco/deco.py)
