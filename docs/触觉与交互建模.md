# 触觉与交互建模

当前触觉描述正在发生的接触，未来触觉预测则可以直接引导动作生成，也可以只在训练时帮助学习交互表征。AdapTac 与 InterAct-Dex 都使用当前触觉，但未来力分支承担不同角色。

| 方法 | 当前触觉如何融合 | 未来预测目标 | 在线动作生成是否使用预测分支 |
| --- | --- | --- | --- |
| AdapTac | 与点云特征双向交互，再由力预测引导融合 | 未来绝对力读数 | 是，先预测力，再生成动作 |
| InterAct-Dex | 按手指调制身体交互特征 | 相对当前力的增量 | 否，只作为训练辅助 |

共享观测与动作数据流见[项目架构](项目架构.md)。两种方法最终都输出 19 维绝对关节目标。

## 触觉表征：force、taxel 与 patch

AdapTac 的触觉编码有三种选择，均输出按五指组织的特征单元（token）。它们对输入的组织方式不同，不代表三个可以互相替换的传感器来源。

| 表征 | 输入与编码方式 |
| --- | --- |
| `force` | 每指三轴汇总力，编码为该指的特征 |
| `taxel` | 每指的密集触觉单元通道，保留通道结构后编码 |
| `patch` | 使用同一密集触觉字段，按预设区域提取描述，再汇聚为每指特征 |

每次使用一种触觉字段，当前观测、未来目标与引导信号保持同源。`patch` 改变的是观测编码方式，未来预测仍针对所选密集触觉字段，而不是区域描述。InterAct-Dex 当前只使用五指汇总力。

Patch 按零力参考构造区域描述；引导信号和未来绝对力目标仍使用同一密集触觉字段的完整归一化变换。默认区域映射是尚未获得 SDK 验证的实验假设，不能据此断言区域与真实传感器表面完全对应。

## AdapTac：未来力引导动作生成

AdapTac 将未来力预测放在动作生成链路中：

1. **视觉与触觉交互。** 点云编码器提取场景特征，触觉编码器提取五指特征；双向注意力让两类特征相互读取信息，再组合观测历史。
2. **预测未来绝对力。** 力扩散模型以交互后的历史特征为条件，预测从当前查询之后的下一观测行开始的力序列。目标是各时刻的绝对力读数，经过同一触觉字段的归一化，而非相对当前力的增量。
3. **引导融合与动作扩散。** 观测力历史与预测未来力共同决定如何读取视觉、触觉特征。融合结果再结合关节状态，作为动作扩散模型的条件。

训练时，未来力真值被加噪，力分支学习恢复对应读数。动作模型使用该分支的预测结果，因此动作损失也能经融合路径反向影响力预测。

推理时没有未来真值，模型先从噪声采样未来力，再据此采样动作。

**显式力损失为零，不等于不使用未来标签。** 即使关闭这项损失，训练仍用未来真值构造加噪的力分支输入，动作损失也仍通过预测力传播。因此该设置不能作为“无未来触觉监督”的对照。

## InterAct-Dex：身体、场景与交互历史

InterAct-Dex 用腕部和五指六个身体槽组织特征，每个槽对应一个 token。实测末端位姿提供身体参考框架，实测指尖位置与关节状态描述手部几何；这里的腕部采用数据约定的末端框架。

身体特征同时读取附近原始点云的局部几何与 PointTransformerEncoder 场景特征，触觉再按手指调制对应表征。历史编码先让同一帧的身体槽交换空间信息，再沿时间读取各自历史；时间注意力保持因果关系，不读取更晚的观测帧。

另一组场景 token 从同一份 PointTransformerEncoder 特征提取独立场景表征。身体历史与场景 token 按帧共同构成动作 Flow 的条件；场景分支不经过身体历史编码器。

### 未来力增量作为训练辅助

设当前查询对应观测行 $q$，$f_q$ 为该行的五指力读数，$h$ 为向后的观测行数。辅助目标为：

$$
\Delta f_h=f_{q+h}-f_q.
$$

例如，$h=2$ 指当前观测之后第 2 行的力变化，不是每次实际执行两个动作。增量归一化时，前后读数的平移项相消，只保留尺度变换。

| 辅助方式 | 用什么预测力变化 |
| --- | --- |
| `encoder` | 最新手指特征与对应跨度内的有序示教动作条件；动作以相对当前关节位置的位移表示 |
| `action_prefix` | 从有效跨度中选取一个，在注意力计算前截断带噪动作序列，再由允许的动作前缀预测增量 |

这些辅助头不参与在线动作生成。辅助权重为零时，InterAct-Dex 关闭相应头，也不读取未来力标签；当前触觉仍通过身体表征参与动作生成。这与 AdapTac 的零显式力损失设置不同。

## 未来标签与有效性

未来力标签必须来自同一回合的真实后继观测行。超出回合边界的填充值不计入力监督；合法零力仍是有效读数，不能当作标签缺失。

AdapTac 只使用至少有一个后继观测的查询时刻。InterAct-Dex 可以保留没有有效后继目标的训练窗口，由有效性掩码排除相应力监督，观测与动作仍可用于策略训练。

未来标签的有效性由源回合边界决定，动作前缀则决定辅助头允许读取哪些动作。二者承担不同作用，不能用动作窗口补齐替代真实后继力标签。

## 仿真与真实数据的边界

仿真触觉是世界坐标系下、以 N 为单位的五指汇总力；位置几何使用一致的世界坐标与米制单位，字段约定见[仿真数据集格式](仿真数据集格式.md)。当前仿真不提供密集 taxel 触觉。

真实汇总力与密集触觉来自不同 SDK 通道，单位与坐标轴尚未统一标定。不能将汇总力视为密集通道求和，也不能在两类读数之间直接重建或替换。密集触觉虽有真实数据生产端，其来源并不自动满足仿真力的物理定义。

策略接口不会自动完成跨来源的单位、坐标与时间对齐。仿真评测只能验证环境实际提供的观测路径；评测协议与结果解释见[仿真评测机制](仿真评测机制.md)。
