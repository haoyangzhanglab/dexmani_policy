# 触觉与交互建模

| 策略 | 闭环执行时的输入 | 交互表征如何影响动作 |
| --- | --- | --- |
| DAI-Flow (`interaction_flow`) | RGB、场景点云与相机标定，关节状态、腕部位姿、指尖位置和五指汇总力 | 每帧手部查询同帧场景，生成六个交互 token。默认两帧形成256个 Scene Tokens 和12个 Interaction Tokens，动作专家依次通过独立的 Scene Cross-Attention、Interaction Cross-Attention 读取；最新关节状态通过 AdaLN 调制。训练时仍预测单帧六个 EMA 未来交互 Tokens。 |
| CordViP | 手部点云、物体点云和关节状态 | 手与物的点云互相查询，手臂与手指状态也互相查询。策略可载入预训练的接触与协调表征。 |
| AdapTac | 场景点云、关节状态和触觉 | 视觉与触觉互相查询。策略先预测未来接触力，再用当前力和预测力融合两种表征，引导动作生成。 |

**DAI-Flow 的单帧编码器**也可独立使用。构建 `encoder = HandObjectInteractionEncoder()` 并加载 RGB 权重后，`encoder(obs)` 返回腕部和五指的交互 token，形状为 `[B,6,192]`。 [DAI-Flow 模型架构](InteractionFlow模型架构.md) · [编码器实现](../dexmani_policy/agents/obs_encoder/interaction/hand_object_interaction.py)

**CordViP 的接触标签**来自手部与物体的几何关系。默认预训练使用逐点接触图，下游策略直接使用原始示教。 [CordViP 预训练](观测预训练.md#cordvip)

**AdapTac 的未来力**在训练时由示教提供监督。力损失只统计回合内有效的未来时刻，梯度累积也使用同一分母。执行时，策略根据当前观测从噪声采样未来力。将 `agent.force_loss_weight` 设为零仅关闭显式力损失，动作损失仍可训练力预测器。默认 `finger_tactile_force` 与 `dexmani_sim` 的观测对应。含密集触觉的数据可用 `tactile=taxel` 训练。 [AdapTac 配方](../dexmani_policy/configs/adaptac.yaml) · [上游方法实现](https://github.com/kingchou007/adaptac-dex/blob/60e2ef1b7b0a29f5d29f5d755e8fe6d048f69fa5/src/adaptac/policy/FFG_policy.py)
