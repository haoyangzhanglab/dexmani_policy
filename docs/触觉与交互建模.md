# 触觉与交互建模

AdapTac 通过未来力引导动作生成。独立的多模态交互编码器为场景和手部分别生成空间 token。

## 触觉表征

触觉可表示为五指汇总力或密集触觉，沿用数据源定义的坐标、单位和尺度。当前仿真提供五指汇总力。

## AdapTac：未来力引导动作生成

AdapTac 先融合场景点云和当前触觉，再用力扩散模型预测未来的绝对接触力。预测结果引导视觉与触觉融合，并结合关节状态生成动作。

训练时对真实未来力加噪，由单次去噪结果引导动作。无效标签在加噪前置零，显式力损失仅对一次更新内的有效元素取均值。关闭显式力损失后，动作损失仍会训练力预测器。部署仅使用当前观测，从独立噪声采样未来力。 [AdapTac 官方实现](https://github.com/kingchou007/adaptac-dex/blob/60e2ef1b7b0a29f5d29f5d755e8fe6d048f69fa5/src/adaptac/policy/FFG_policy.py)

## 多模态交互编码器

多模态交互编码器当前未接入现有策略。场景分支以相机标定融合点云局部几何与 RGB，可在 patch 中心或有效邻域采样图像特征。手部分支以腕部、五指位置和原始触觉为输入，读取场景几何。两个分支各自输出空间 token 和对应位置。

## 手部几何与触觉融合组件

### 几何坐标与尺度

场景点云、末端位姿和指尖位置使用同一 Base-aligned 米制坐标，外参将该坐标变换到 OpenCV Camera 坐标系。仿真 World 与 Base 重合，Real 点云和 FK 几何直接使用 xArm Base。末端 6D 旋转由旋转矩阵的前两列依次组成，指尖局部坐标以腕部为原点。 [数据集坐标](仿真数据集格式.md#几何坐标)

腕部位置、腕部局部指尖和手部到场景的相对位置使用独立的输入尺度，输出的几何锚点保留原始米制坐标。

### 相对几何注意力

手部 token 单向读取场景 token，手部锚点与场景点的三维相对位置为注意力提供偏置。

### 触觉门控融合

手部 token 按腕部、拇指、食指、中指、无名指、小指排列。融合组件读取同序的五指原始力，通过触觉门控残差更新手部 token。零力时更新恒为零。

门控残差和全局汇总借鉴 DeCAL，手指身份编码借鉴 DexTacWAM，逐特征门控借鉴 DECO。 [DeCAL](https://github.com/AureleoPKU/DeCAL/blob/09de1855cfc933a2d2680d6011744476647ed7d1/src/lerobot/policies/DeCAL/modeling_decal.py) · [DexTacWAM](https://github.com/dextacwam/DexTacWAM/blob/4f7c5a80dda2ca06667a9a583075d8c92108eb56/models/tactile_models/visual_vae_adapter.py) · [DECO](https://github.com/BAAI-Humanoid/DECO/blob/fdd159e2a149ff0b91f001569ae7e9d60220697c/models/deco/deco.py)
