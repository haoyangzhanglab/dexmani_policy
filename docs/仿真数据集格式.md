# 示教数据格式

示教按任务保存为 Zarr，训练时用 `zarr_path` 指定数据集。仿真示教、真机导出和 DexJoCo 数据使用各自的动作表示。

## 回合与时序

**当前观测 → 执行动作目标 → 下一帧观测**

每帧的观测在执行该帧动作前取得。实测关节状态描述机器人当时的关节位置，动作描述控制目标。`meta/episode_ends` 标记回合或连续段的结束位置，`task_name`、`dt` 和 `action_space` 描述任务、控制周期和动作空间。训练和评测使用相同的控制周期。

| 来源 | 机器人状态 | 动作目标 |
| --- | --- | --- |
| dexmani_sim / dexmani_real | `joint_state` | `action` 记录关节目标，`action_ee` 表示末端位姿和手部目标。真机 ODE 使用 `action_ode`。 |
| DexJoCo | `proprio` | `action_rotvec` 表示末端位置、旋转向量和手部目标。 |

真机 ODE 的目标来自完整命令的提交记录。 [ODE 数据约定](手部动作表示.md#ode从上一条指令积分生成轨迹)

## 主要模态

| 模态 | 用途 |
| --- | --- |
| 机器人状态 | 描述关节、末端和指尖的实测状态 |
| 图像与相机标定 | 通过 RGB、深度和相机参数关联图像与空间位置 |
| 场景点云 | 描述相机可见的场景几何 |
| 手部与物体点云 | 描述手和物体的几何，可包含被遮挡的表面 |
| 触觉 | 描述手指接触力，可用于未来力监督 |

## 几何坐标

当前 `dexmani_sim` 的世界坐标系与机器人基座重合，`dexmani_real` 的几何数据使用 xArm 基座坐标。两者均使用米，投影时由相机外参将基座坐标变换到相机坐标。 [多模态交互编码器](触觉与交互建模.md#多模态交互编码器)

DexJoCo 使用 MuJoCo 世界坐标，点云位置单位为米，颜色范围为 `[0,1]`。状态以 `wxyz` 四元数表示末端旋转，动作使用旋转向量。双臂数据按右臂、右手、左臂、左手排列。

## 从轨迹到训练样本

- 仿真按回合划分训练与留出数据。真机用 `source_episodes` 标记原始采集，同一采集的连续段归入同一组。`val_episodes` 和 `max_train_episodes` 按组计数。
- 观测历史和动作窗口在一个回合或连续段内截取。启用填充时重复该段首尾帧。新拟合的归一化统计只使用训练部分。
