# 示教数据格式

示教按任务保存为 Zarr 2 目录。默认路径为 `robot_data/dexmani_sim/<task>.zarr`，DexJoCo 使用 `robot_data/dexjoco/<task>.zarr`。其他位置可通过 `zarr_path` 指定。

## 回合与时序

`data/<字段名>` 的第一维是时间。索引 $k$ 的观测在控制时刻 $k$ 采集，同一索引的动作是随后执行的目标。`meta/episode_ends` 给出各回合或连续段的结束下标，区间左闭右开，末值等于总帧数。根属性 `task_name`、`dt`、`action_space` 分别记录任务、控制周期（秒）和动作空间。

| 数据来源 | 实测状态 | 示教动作 |
| --- | --- | --- |
| dexmani_sim / dexmani_real | `joint_state` | `action` 为绝对关节目标，`action_ee` 为末端位姿及手部目标 |
| DexJoCo | `proprio` | `action_rotvec` 为末端位置、绝对旋转向量及手部目标 |

真机示教中的 `action` 沿用本段最近一次成功提交的完整目标。 [ODE 的动作对齐](手部动作表示.md#ode-的动作对齐)

## 几何坐标

- **dexmani_sim / dexmani_real** 的点云位置单位为米。仿真世界系与机器人基座系重合，真机以 xArm 基座为原点。相机外参将基座坐标变换到相机坐标，内参将相机坐标投影为像素。RGB 按 `[H,W,3]`、`uint8` 存储。 [DAI-Flow 的输入与输出](InteractionFlow模型架构.md#输入与输出)
- **DexJoCo** 使用 MuJoCo 世界系，点云位置单位为米，颜色范围为 `[0,1]`。`proprio` 中的末端旋转为 `wxyz` 四元数。双臂顺序为右臂、右手、左臂、左手。配方的 `center_rotvec` 将动作旋转转到绕世界 x 轴旋转 π 的参考系，推理后再还原。

场景点云来自相机可见区域。独立的手部和物体点云可包含被遮挡的表面，CordViP 用它们生成逐点接触标签。AdapTac 使用示教中的触觉力监督未来力预测。 [触觉与交互建模](触觉与交互建模.md)

## 从轨迹到训练样本

仿真示教按回合划分。真机按 `source_episodes` 将同一次采集的连续段放进同一组，`val_episodes` 和 `max_train_episodes` 均按组计数。归一化统计只用训练组拟合。

同一个样本的观测历史与动作窗口来自同一回合或连续段，需要填充时重复首尾帧。 [动作窗口示例](InteractionFlow模型架构.md#训练期-future-interaction-latent)

### DAI-Flow 的未来观测

`interaction_flow` 配方通过 `dataset.future_obs_steps=${n_action_steps}` 从已有观测字段读取单帧未来目标，无需在 Zarr 中新增标签或预先保存 Latent。训练 batch 的结构为：

| 字段 | batch 后形状 | 用途 |
| --- | --- | --- |
| `obs` | 各模态 `[B,n_obs_steps,...]` | 当前条件 |
| `action` | `[B,horizon,action_dim]` | FM 监督 |
| `future_obs` | 各模态 `[B,...]` | EMA Interaction Encoder 的输入 |
| `future_obs_valid` | `[B]`，bool | 排除跨回合的 Future Loss |

偏移从最新观测经过 Padding 裁剪后的真实行号起算。默认两帧观测、8 步执行时，普通窗口中的目标是索引 9。目标达到或超过回合结束下标时，读取本回合最后一帧并标记无效；FM Loss 仍使用该样本。详见[时间对齐](InteractionFlow模型架构.md#时间对齐与有效性)。
