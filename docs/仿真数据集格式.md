# 示教数据格式

示教按任务保存为 Zarr 2 目录。默认路径为 `robot_data/${task_name}.zarr`，`eval/dexjoco` 配方使用 `robot_data/dexjoco/${task_name}.zarr`。用 `zarr_path` 指定其他位置。

## 回合与时序

- `data/<字段名>` 按时间排列。每帧先采集观测，再执行该帧的动作目标。
- `meta/episode_ends` 记录每个回合或连续段的结束下标，采用左闭右开区间，末值等于总帧数。
- Zarr 根属性 `task_name`、`dt` 和 `action_space` 分别记录任务、控制周期（秒）和动作空间。评测环境的控制周期须与训练数据一致。

| 来源 | 机器人状态 | 动作目标 |
| --- | --- | --- |
| dexmani_sim / dexmani_real | `joint_state` | `action` 为关节目标，`action_ee` 为末端位姿及手部目标 |
| DexJoCo | `proprio` | `action_rotvec` 为末端位置、绝对旋转向量及手部目标 |

真机 ODE 使用 `action_ode`，记录最近确认的完整关节目标。 [ODE 数据约定](手部动作表示.md#ode从上一条指令积分生成轨迹)

## 主要模态

除机器人状态外，配方可读取 RGB、深度、相机标定、点云和触觉。`rgb` 以 `uint8` 存储。场景点云来自相机可见区域，手部和物体点云可包含被遮挡的表面，触觉数据可用于未来力监督。

## 几何坐标

- `dexmani_sim` 的世界坐标与机器人基座重合，`dexmani_real` 使用 xArm 基座坐标。位置单位为米，相机外参用于从基座坐标变换到相机坐标。 [多模态交互编码器](触觉与交互建模.md#多模态交互编码器)
- DexJoCo 使用 MuJoCo 世界坐标，点云位置单位为米，颜色范围为 `[0, 1]`。`proprio` 用 `wxyz` 四元数保存末端旋转，双臂数据按右臂、右手、左臂、左手排列。

DexJoCo 配方启用 `center_rotvec`。DP 和 DP3 在归一化前将每臂的动作旋转转换到绕世界 x 轴旋转 π 的参考系，推理时再还原为环境所用的绝对旋转向量。

## 从轨迹到训练样本

- 仿真数据按回合划分，真机数据按 `source_episodes` 将同一次原始采集的连续段分为一组。`val_episodes` 和 `max_train_episodes` 按组计数。
- 观测历史和动作窗口均取自单个回合或连续段。填充时重复首尾帧。归一化统计只使用训练数据拟合。
