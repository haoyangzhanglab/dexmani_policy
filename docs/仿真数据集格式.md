# 仿真数据集格式

仿真示教按任务保存为 `robot_data/<task_name>.zarr`，每个数据集包含多个 episode（回合）。数据模块将连续轨迹转换为策略学习所需的时序样本。

## 回合与时序

Zarr 的 `data/` 沿时间轴保存各模态，`meta/episode_ends` 标记回合边界。根属性 `task_name`、`dt`、`action_space` 分别描述任务、控制周期和采集动作空间；当前训练使用 joint 采集数据。

每帧记录动作执行前的观测，以及随后执行的动作目标：

**当前观测 → 执行动作目标 → 下一帧观测**

实测关节状态描述机器人当时的位置，动作描述希望到达的目标，两者不能互相替代。控制周期随策略 checkpoint 保存，用于保持训练与执行的时间尺度一致。

## 主要模态

| 模态 | 内容与用途 |
| --- | --- |
| 机器人状态 | 关节位置、实测末端位姿和指尖位置，描述身体状态与手部几何 |
| 图像与标定 | RGB、深度及相机参数，用于视觉编码和图像与点云的空间对应 |
| 场景点云 | 相机可见的场景几何，为策略提供空间条件 |
| 手部与物体点云 | 来自几何模板的形状信息，可包含遮挡表面，用于手物交互建模 |
| 触觉 | 仿真中的五指汇总接触力，用于接触感知和未来力监督 |
| 动作 | 绝对关节目标，或由 joint 目标经 FK 派生的末端位姿与手部目标，作为学习监督 |

各方法使用不同模态组合，几何计算依赖一致的坐标与单位。字段定义与读取入口分别位于 [common/config.py](../dexmani_policy/common/config.py) 和 [datasets/episode_store.py](../dexmani_policy/datasets/episode_store.py)。

## 从轨迹到训练样本

1. 按回合划分训练与留出数据，新拟合的归一化统计仅使用训练回合。
2. 在所选回合内提取观测历史与动作窗口；窗口不跨回合，padding 重复本回合首尾帧。
3. 按方法补充上一条动作、接触标签或未来力等输入与监督，再交给策略学习。

核心实现位于 [datasets/](../dexmani_policy/datasets/)，模块关系见[项目架构](项目架构.md)。
