# 仿真数据集格式

仿真示教按任务保存为 Zarr 数据集，每个任务包含多个 episode（回合）。数据模块将连续轨迹转换为策略学习所需的时序样本。

## 回合与时序

每帧记录动作执行前的观测，以及随后执行的动作目标：

**当前观测 → 执行动作目标 → 下一帧观测**

实测关节状态描述机器人当时的位置，动作描述希望到达的目标，两者不能互相替代。实测末端位姿与末端动作目标也具有同样区别。

Zarr 根属性为 `task_name`、`dt`、`action_space`，接触标签预处理保留这三项属性。策略训练要求 `task_name` 与训练配置一致、`action_space="joint"`，并要求 `dt` 为有限正数；缺失字段直接报错。`action_ee` 是实际 joint 目标通过 FK 派生的动作，即使训练选择该字段，采集动作空间仍为 joint。周期自动保存到 checkpoint 的 `effective_config.control_dt_s`，`PolicyInfo.control_dt_s` 直接读取它。

回合边界由独立的回合记录确定。训练窗口不会跨回合，动作后的终止标记用于描述交互状态。

## 主要模态

| 模态 | 内容与用途 |
| --- | --- |
| 机器人状态 | 关节位置、实测末端位姿和指尖位置，描述身体状态与手部几何 |
| 图像与标定 | RGB、深度及相机参数，用于视觉编码和图像与点云的空间对应 |
| 场景点云 | 相机可见的场景几何，为策略提供空间条件 |
| 手部与物体点云 | 来自几何模板的形状信息，可包含遮挡表面，用于手物交互建模 |
| 触觉 | 仿真中的五指汇总接触力，用于当前接触感知和未来力监督 |
| 动作 | 绝对关节目标或末端位姿与手部目标，作为策略学习的监督 |

各方法使用不同模态组合。几何计算依赖一致的坐标与物理单位；仿真汇总力与真实密集触觉具有不同来源，不能仅凭字段相似互换。

固定维度的普通观测由 `dexmani_policy/common/config.py` 的 `FIELD_FEATURE_SHAPES` 定义，触觉输入由独立的 `TACTILE_FEATURE_SHAPES` 定义：

| 字段 | Zarr Shape |
| --- | --- |
| `joint_state` | `[T,19]`，手臂 7 维与手部 12 维 |
| `eef_pose` | `[T,9]`，位置 3 维与 Rot6D 6 维 |
| `fingertip_xyz` | `[T,5,3]` |
| `camera_intrinsic` | `[T,9]` |
| `camera_extrinsic` | `[T,12]` |
| `finger_tactile_force` | `[T,5,3]` |
| `taxel_tactile_force` | `[T,5,120,3]` |

这些字段必须存储为浮点数据。`EpisodeStore` 打开所选字段时检查 Shape 和 dtype，策略 Dataset、观测预训练及接触标签预处理共用此边界；检查只读取数组元信息，不扫描观测值。浮点观测在取样时转换为 FP32。训练的固定字段维度及 limits affine Shape 与上述定义一致，identity 字段不创建 Normalizer buffer。

仿真评测和部署通过 `prepare_observations()` 使用同一份 Shape 定义，接收带时间轴的观测历史并取最后 `n_obs_steps` 帧；非 RGB 数值输入转换为 FP32 后检查有限值。`joint_state` 和 `eef_pose` 的输入宽度固定为 19 和 9，不由 checkpoint 的 `normalization_dims` 改写。

普通策略支持非空点数及可转换浮点精度；手物 XYZ 由 Dataset 通道选择读取，不要求身份元数据。当前链路只包含仿真数据生成、策略训练和仿真评测，不从数据提取 Real 部署配置。续训允许替换数据路径，但数据 `dt` 必须与 checkpoint 的 `control_dt_s` 一致（`rtol=1e-6`、`atol=1e-9`）；控制周期和归一化参数沿用 checkpoint，不用替换数据的周期覆盖。

## 从轨迹到训练样本

数据模块按方法需要提取观测历史和动作窗口，再交给策略编码与学习。训练与留出数据按回合划分，新拟合的归一化统计仅使用训练回合。窗口索引只包含所选回合中满足窗口长度与 padding 条件的样本，保持回合和帧的原始顺序；padding 重复本回合首尾帧，不跨越回合边界。

ODE 保持原始 Zarr 的动作行约定，用 `action[N-1:N-1+H]` 监督未来 H 步。`ODEDataset` 另返回顶层 `prev_action: float32[19]`：普通帧取同回合上一条原始指令，回合首帧取未增强的实测状态。该字段不进入观测模态或归一化统计，使用 action affine；末尾沿用最后动作重复 padding。

观测预训练可从轨迹中学习场景变化或手物接触关系；触觉方法还可使用同一回合的后继观测构造未来力目标。它们提供的监督不同于动作目标。

模块关系见[项目架构](项目架构.md)，触觉的作用见[触觉与交互建模](触觉与交互建模.md)。
